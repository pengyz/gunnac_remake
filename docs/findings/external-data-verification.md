**伤害命中双路真身（A 级，bank14:$D67C-$D6BB）**：

```
D67C  LDA $4C / BEQ →跳过          ; $4C=伤害使能门
D680  LDY $6E / BPL 路B            ; **$6E bit7 = 双路开关**
      路A（bit7=1）：LDA $0630,X / SEC / SBC #$02   ; **HP 恒定 −2**（$D688=1# −2HP 三方一致真身 ✓）
      路B（bit7=0，Y=$6E）：$0668+Y|= $20 /

```
