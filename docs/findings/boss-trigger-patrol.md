# BOSS 出场触发链 + 巡逻语义首批（t89）

> ①触发链：目录尾字段 → $9F/$A0 → 生成例程 $865C（sub_8619 VM 分派调用）——
> **出场触发 = VM 流推进本身**；②巡逻语义三条定谳；③BOSS/后半分界部分收。
> 达标口径：三条目语义 ✓（findings §2）。

## 1. 出场触发链（①）—— **VM 流推进即触发**（A/B 级）

**链路实证**：

```
目录表字段 6-7（bank00:$802A-$8032）→ $9F/$A0 = 尾记录基址（STG-1=$A16F）
   ↓ 消费：bank00:$865C-$869E 生成例程
$865C:  $48C,Y / $470,X ← 亚像素；($9F)[$10&$1F] → $0400,X（类型）
        $11<<4 → $04E0,X（X 坐标）；$92−$91+$E0 → $04FC,X（Y 坐标）
        $8E+2×$11 → $0614,X；$8D-$92 → $05F8/$0710/$072C,X（参数）
   ↑ 调用方：sub_8619（VM 位掩码执行器，t59）→ JSR $865C
```

| 裁定 | 内容 | 级 |
|---|---|---|
| **出场触发 = VM 指令流推进到生成段**（无独立触发例程——脚本时间线本身即触发） | A |
| **波次耗尽/关卡结束 = 流 END 字节**（$97/VM 流终止 → 阶段推进）；独立『耗尽判定』例程未见 | B |
| 生成例程 = **$04xx 网格生成层写者**（类型/坐标/参数九字段）——t32 网格的生成侧定谳补全 | A |
| flow 状态机跃迁点（StageStart→Combat→?）：脚本流段边界 = 跃迁候选；trace 层未逐帧对齐（W30） | C |

## 2. 巡逻语义三条（②，达标）—— VM 字节码逐码

**`$A41F/$A435` 巡逻主体**（3B 分组解析：CALL {码,ptr} / INSTR {码,p1,p2} / FC {码,±值} / FE {码,ptr} / 00=END）：

```
$A435: 02 41 A4（CALL $A441 运动原语）| 03 00 00（INSTR 3）| FC FE（X−2）| FE 35 A4（自环）| 00
$A41F: 02 41 A4 | 08 00 00 | FE 1F A4（自环）| 00 ‖ 02 41 A4 | 03 00 00 | FC 02（X+2）| FE 35 A4 | 00 ‖ …
$A486: 01 9C A4（CALL $A49C）| 05 00 00 | FE 86 A4（自环）| 00 ‖ … FC 03（X+3）| FE 90 A4 …
```

| # | 语义 | 证据 | 级 |
|---|---|---|---|
| 1 | **`FC ±v` = X 轴巡逻位移**（$A41F 段 FC 02 / FC FE 交替 = **左右往复扫描**） | 字节实录 | A |
| 2 | **`FE ptr` 自环 = 持续/重复段**（$A41F/$A435/$A486 自环 = 巡逻驻留） | 字节实录 | A |
| 3 | **`CALL $A441/$A49C` = 运动原语子脚本**（被巡逻段反复调用）；子脚本内参数化（`$A441` 首记录指针字段落非窗值，参数表/子流二读 → 残余 W31） | 结构 | B |

- `INSTR n`（03/05/08 等）= 段参数/状态指令（语义待 VM 指令码表逐码展开，t59 W13 延续）。

## 3. BOSS 实体 vs 后半波次分界（③）—— 部分收（如实）

- `($9F)` 消费 = **逐字节类型表读**（`[$10&$1F]` 32 项索引 → `$0400,X` 类型）与 t83 的
  **5B 记录族读法并存**（同区双读）——分界判据未定（W32）。
- `sub_8619` 位掩码分派（t59）→ `$865C` = 通用生成通道（BOSS/后半/普通敌同通道）——
  **实体区分不在生成层而在类型/参数** → 需逐记录类型值对照（下批）。

## 4. BOSS 升格材料（报 captain，登记归 spec-writer）

- **可入规则素材（B→A 级）**：R-boss-patrol-1（FC±2 左右巡逻）、R-boss-patrol-2（FE 自环驻留）、
  R-boss-patrol-3（CALL 运动原语）——三条语义齐。
- **升格判据**：触发链已定（VM 流推进）但『BOSS 实体识别』（W32）与 flow 跃迁对齐（W30）未闭
  → **建议 BOSS 子格维持 L2/部分，巡逻子项可先升**（裁定归 captain）。
