# 地址寄存器相位陷阱取证（t97）— $2006 写点替代法 + 上传地址序列重建

> ①`$2006` 硬件寄存器写点**插桩不可行**（Mesen2 内存回调不覆盖 I/O 寄存器区，注册成功但 0 触发）→
> **W33 替代法成立**：地址源 RAM（`$8E/$8F`）写流 = NMI 时值真值来源；②地址序列重建 +
> 步进对齐证据；③R-l4-linebuf 地址维补全（§3）。

## 1. 插桩结果与替代法（①）

| 尝试 | 结果 |
|---|---|
| `probe_mem 2005 2006`（CPU 地址 $2005/$2006 写回调） | 注册成功（cb:true）但 **0 事件**——Mesen2 `addMemoryCallback` 不覆盖 **I/O 寄存器区**（$2000-$401F），与 t94 RAM 区行为不同（如实入 W36） |
| **W33 替代法：`probe_mem 008e 008f`**（地址源 RAM 写流） | **成功**：1,158 写事件 / 300 帧 |

**地址源定谳（A 级，seed 静态 + 写流动态双证）**：`bank15:$F083-$F097`：

```
$F083: LDA $8E / ADC #$0F / STA $02     ; $02 = $8E + $0F（段基址 lo，进位→$7E）
$F092: LDY $8F / STY $2006 / STA $2006  ; ★$2006 对：hi=$8F，lo=$02
$F0D6: LDA $02 / ADC #$20 / BNE $F092   ; 组间步进 +$20（lo）
```

→ **上传地址 = `$8F : ($8E+$0F)`**；组内步进 **+$20**（lo）；`$7E`=进位段标记。
t96『$8E/$8F 快照不可用』的更正注记：**快照不可用 ≠ 写流不可用**——回调捕获的是逐次写值
（NMI 时值）✓ 相位陷阱绕过。
