## 3. ③t126 门控段逐指令重推 —— ✓ 成立

```
E7DC: JSR sub_E7ED
E7DF: LDA $1B / E7E1: AND #$18 / E7E3: BNE locret_E7EC   ; ($1B&$18)!=0 ⇒ 不写
E7E5: LDA $1A / E7E7: BMI locret_E7EC                    ; $1A bit7=1 ⇒ 不写
E7E9: JMP sub_F030                                       ; 否则寄存器写
```

写使能 = `($1B & $18)==0 && $1A bit7==0` **与 t126 复刻逐指令一致** ✓（附注：`sub_E7ED` 为 $1A bit7=1 时的 $2000 回写路径，与门控互补）。
