# 弹对象槽位几何/分配器定谳（t48）— shots golden 转正前置

> 方法：生成例程 bank3:$A1FD 写点追踪 + 分配器 $888D 逐指令反汇编 + **L2 四用例三方全等实测**
> + gameplay-stage1 弹数 churn 对照。t45 未证域收口。

## 1. 槽位几何定谳（A 级：字节 + L2 实测）

**分配器 `bank2:$888D-$88BA` 逐指令实证**：

```
$888D: LDY #$80           ; 起始偏移 $80
$888F: CLC / LDA #$04 / STA $04   ; 4 组
$8894: LDA $040E,Y / BEQ $88BA    ; 空槽判定：state==0 → 命中返回（Y=槽偏移）
        （组内连续查 5 槽：Y, Y+1, Y+2, Y+3, Y+4）
$88B1: TYA / ADC #$18 / TAY       ; 组间跳：末查位+1（$84+0x18=$9C）
$88B5: DEC $04 / BNE $8894        ; 共 4 组
$88B9: SEC / RTS                  ; 全满（carry=无空槽；Y=$F0、A=$F0=TYA/ADC 遗留）
```

| 结论 | 值 | 级 |
|---|---|---|
| **槽位 stride** | **1（字节偏移）**，组内连续 | A |
| **槽位集合** | **$80-$84, $9C-$A0, $B8-$BC, $D4-$D8**（4 组 × 5 = **20 槽**） | A |
| **组距** | **$1C**（$80/$9C/$B8/$D4 递增 $1C）——与 $1C 网格同格交错 | A |
| 空槽判定 | `$040E+Y == 0`（state 字段为 0） | A |
| 分配策略 | 首次适应（组序 × 组内序扫描，低偏移优先） | A |
| 回收 | state:=0（生成方写 `$040E,Y=1` = 占用，寿命倒数至 0 即空） | A |
| 满载路径 | SEC，Y=A=$F0（`TYA/ADC #$18` 遗留值） | A |
| 字段布局 | 六数组基址 $040E/$047E/$04EE/$055E/$05CE/$063E（$70 间距，t32）+ 同槽偏移 Y | A |

**t45 矛盾解**：stride-1 全域解析会跨过 $18 组间空隙（错读越界偏移）；五字段同帧签名的
18 例矛盾值 = 组间空隙伪读。真实几何 = **组内 stride 1 + 组距 $1C 的 20 槽**。

## 3. 弹数 churn 对照（gameplay-stage1，A 级）

> 【2026-10-12 更正（t53，t50 F2 证伪）】本节 churn 统计**口径不成立**，原文保留不删：
> ①所计 20 槽 state（$048E-$0492/$04AA-$04AE/$04C6-$04CA/$04E2-$04E6）实为 **B5 交错区静态非寿命数据**
> ——20 帧不递减，且与 $1C 网格同址交错（敌/关卡对象区串扰），"并发最大 9≤20"不反映弹对象并发；
> ②"921 帧零弹=计数器未到周期"的解释被 t50 F1 反证（六型生成器全程零活动：五字段写入链 0 命中、
> `$072E,X` 恒 0）——真弹对象归因不成立；③容量/满载 SEC 未触发的结论随口径作废。
> 真弹对象统计待 t52 交错语义定谳后重采；`--shots-extract` 维持实验入口（shots golden 不入库）。

- 20 槽 state 地址（$048E-$0492/$04AA-$04AE/$04C6-$04CA/$04E2-$04E6）逐帧计数：
  **并发最大 9**（帧分布 0:921 / 4-9:169）——**容量 20 未饱和**（满载 SEC 路径未见触发），
  4-9 并发与六型自动连射（每型 1-2 发在途）相容。
- 负注：921 帧零弹 = 六型计数器未到周期/弹短寿命（寿命=$892F 时长表逐段倒数），
  非几何问题。
