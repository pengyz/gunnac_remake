## 1. 独立重导（ROM 直读，不采信被审数字）

### 1.1 `sub_ECBF` 清零字节族（AR63-1 铁证复核）

```python
rom=...; off = 0x10 + 0xECBF + 0x10000 = 0x1ECCF    # bank15 固定 $C000-$FFFF → file
print(rom[off:off+11].hex(' '))
# => a0 06 a9 00 99 e0 00 88 10 fa 60
#    LDY#6 / LDA#0 / STA $E0,Y / DEY / BPL -6 → $ECC3(STA) / RTS
```

- 逐字节：`A0 06`(LDY#6) `A9 00`(LDA#0) `99 E0 00`(STA $E0,Y) `88`(DEY) `10 FA`(BPL rel=-6→`$ECC3`=STA) `60`(RTS)。
- Y=6..0 ⇒ 清 **`$E0-$E6` 全 7 字节**，与 AR63-1 结论、被审修正注（ECBF-ECC9 清零 7B）**完全一致** ✓。
- 备注：任务书给的族 `A0 06 A9 00 99 E0 00 88 10 F8` 中 BPL 偏移 **实为 `FA` 非 `F8`**（回跳至 STA `$E0,Y` = `−6`）；操作码族 `A0 06 A9 00 99 E0 00 88 10 xx 60` 一致，结论不受影响——按 ROM 实字节记录。

### 1.2 `A390` 跳过减一（AR63-2 铁证复核）

```python
off = 0x10 + 0x6390 = 0x63A0    # bank03:$A390 ← PRG 0x6390
print(rom[off:off+2].hex(' '))   # => d0 08   (BNE loc_A39A)
print(rom[0x10+0x639F:0x10+0x639F+3].hex(' '))  # => 4e 8e 01  (LSR $018E)
```

死亡结算走向（bank03，ROM 直读 `ad 8d 01 d0 0b 20 56 ed a5 26 09 08 85 26 d0 08 / a0 01 20 03 ed 8d 8d 01 …`）：

```
$A382 LDA $18D / $A385 BNE A392      ; $18D≠0(非终死)→减一
$A387 JSR $ED56 / LDA $26 / ORA #8 / STA $26   ; 终死：$26|=8
$A390 D0 08  BNE loc_A39A            ; ← 跳过 $A392 减一（$26 刚置位恒≠0，BNE 必走）
$A392 LDY #1 / JSR $ED03 / STA $18D  ; 命数 BCD −1（仅非终死执行）
$A39A LDA #$21 / JSR $ED3B           ; 音效
$A39F LSR $18E                       ; 金钱减半
$A3A2 JSR $CB4F                      ; trampoline
```

- **`A390 BNE` 确在 `$26|=8` 之后跳过 BCD 减一**，`$18D` 终死恒 0、**无借位** —— 与 AR63-2 结论、被审列示（L99/L100 "仅非终死执行"）一致 ✓。
- **"仅非终死执行"限定准确**：减一 `A392` 仅当 `A385 BNE` 走（`$18D≠0`，非终死）才执行；终死路径被 `A390` 跳过 ✓。
