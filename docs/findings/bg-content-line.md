# 地形 BG 内容线（t69）— $AC80 映射 + STG-01 BG 时间线

> 方法：桥指令重读（stride 更正）+ tile 流格式试切分 + gameplay-stage1 `$1C/$1D` 逐帧滚动时间线。
> 含 t64『×3』证据更正与 Wv 系列残项裁定。

## 1. 桥 stride 更正（t64 证据更正）—— **×5 而非 ×3**

t64 §1 桥算式 `ASL/ROL/ASL/ROL/ADC $150,X` 逐指令重读：

```
v → ASL (2v) → ASL (4v) → ADC v = **5v**（ROL 链处理进位字节）
```

→ **`$150,X` 索引 × 5 = 5 字节记录步长**（与 t_005 记录同规格：4 字段+标志字节）。
t64『索引 ×3』**更正为 ×5**（N-0088）；桥的 5 字节记录读取（$85CE-$85EA 连续 5 LDA）与之自洽 ✓。

## 2. $AC80 tile 流（部分收口 + 负结果）

- 字节实录（file 0x10C90）：`65 66 67 39 00 80 00 04 08 38 08 5C 01 02 5F 1D 39 80 00 07 …`
  —— 含 tile 码值域（$60-$75 族）+ `00 80`/`39` 复现标记。
- 5 字节记录试切分（对齐 $AC80）：`(65 66 67 39 00)(80 00 04 08 38)(08 5C 01 02 5F)…` —
  首记录 4 字段 {65,66,67,39}+标志 00 形似 tile/属性组，但**无稳定对齐复现**（`00 80` 周期与
  5 字节错位）→ **格式定谳未成立**（C 级，W21）。
  > 【2026-10-12 更正（t78/t76，N-0097/0098 联动）】"5B 试切分"系**错误格式假设**：5 字节记录
  > 是**桥侧图案表规格**（`$7A/$7B` 表 5B 记录，另一张表），与 `$AC80` 流**无关**——无对齐不是
  > 流格式未定的证据，而是切错了格式族。`$AC80` 流=**`$97` 解释器 4B/6B 记录流同族候选**
  > （N-0099：4B/6B 对齐试切分不稳=字节级归属残余 W21′）；本节负结果历史保留（W21 由"格式未知"
  > 收窄为"字节级归属"）。
- 消费方反查：`$AC80/$AC85/$ACE0` 字面 xref **0 命中**（间接寻址）；`$ACA0` 命中系
  `LDY #$AC` 字节邻接巧合（data-island 族第五例）；`bank00:$9625` 的 `LDA #$87/LDY #$AC`
  = 对象例程传参（类型/参数），**非指针**（W22 更正 t42 线索）。
- **Wv-2（FD 标记）**：t59 VM 指令集 `$FD` = 循环计数装入（A 级）——但 $AC80/波次链 FD 字节与
  该 opcode 的对应**未证**（格式未定）→ Wv-2 维持（部分素材入档）。
- **Wv-3（16 帧定时）**：BG 侧未现身（本链滚动脉冲 = 120 帧周期，见 §3）→ 负注。

## 5. 复现命令

```bash
python3 - <<'PY'
import json
prev=None; cur=None
for line in open('analysis/traces/gameplay-stage1.frames.jsonl'):
    r=json.loads(line)
    if r['f']<1150: continue
    zp=bytes.fromhex(r['w']['zp']); v=(zp[0x1C],zp[0x1D])
    if prev:
        dx=(v[0]-prev[0])%256; dy=(v[1]-prev[1])%256
        s=(dx if dx<128 else dx-256, dy if dy<128 else dy-256)
        if s!=cur: print(r['f'],s); cur=s
    prev=v
PY
xxd -s 0x10C90 -l 96 rom/gunnac_cn.nes   # $AC80 流
```
