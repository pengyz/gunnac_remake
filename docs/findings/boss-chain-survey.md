## 4. 【2026-10-17 E-W07 ①收口】切换判据全谱定谳——节拍驱动+HP 表重装（非 HP 阈值）

**$CB 循环体三维护合（A 级，AD3C-ADCF 全段）**：

```
AD41  $48C 状态分支 → HP 初装：$ADED[$4D]（状态0）/ $ADE5[$4C]（状态≠0）→ $0630
AD5B  状态二判 → AD60：$2B&$3F==0（**64f 节拍**）→ DEC $6F4（**退场倒数**）
        耗尽 → 参流 $ADF3 + **JMP $D10C 回收**
AD85  **$D0<5 判** → ADA4 重装支：$ADE5[$4C]→HP / $ADE9[$4C]→$6BC（节拍周期）
        → $C5DF **节拍计数器**（$6A0 倒数，周期=$6BC；CLC=到点=转换信号）
        → 到点：装参模式切（$11:=$05 路）+ $C474 动作
```

**$C5DF=节拍计数器（A 级）**：`DEC $06A0,X / BNE(未到点) / $6BC,X 重装 / CLC / RTS`——
**转换判据主驱=节拍到点**（周期参=$6BC 表值）。

**E-W07 ①答案**：「HP 阈值 vs 计时」= **计时节拍驱动 + HP 表重装制**（HP 归零≠相位触发；
相位转换=节拍到点+$D0 状态+条件）——**多相 HP 面=表切换**（初装 $ADED[$4D]/重装 $ADE5[$4C]）。
**相位参数表全谱**：$ADED（初 HP）/$ADE5（重装 HP）/$ADE9（节拍周期）/$A3B4+$A3BC（行为参对）。
相位数终值（$D0 维 <5 判=状态数候选上限 5）待 trace 确认（考证面①插桩残项）。
