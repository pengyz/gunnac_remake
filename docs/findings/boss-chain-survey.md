## 1. boss 生成链定谳（A 级——行为 VM 调用面）

```
关 8 终段波次流（型 $CA 记录，$FFFF 流尾哨兵族）
  → dispatch：type $CA → bank7:$A6EC（批 3 ⑧生成器）
      $A6EC：$C304 槽分配 → **$0400,Y:=$CB（生成 boss 主体 ×N）** + 速度/参数装
  → type $CB → bank7:$ACE5：
      $ADF4 轨迹 helper（$EBF4 表×$4FC/$4E0 速度参→$5F8/$614）
      → **$048C 分派（状态机）** → 状态支：
        AD13 支：JSR $D25A 装参流（$ADF1）+ **$C304→LDA #$CD/JSR $C430（生成部件 type $CD）**
        + $48C,Y:=$01 + $4C 表参（$ADE1→$6BC）+ RNG（EC12&$1F+3）
      死亡门 $ADCF：$0630,X==0 → 装参 $ADF2（死亡态流）
  → type $CD → bank7:$AEB0（部件行为：$48C 二态+$D25A 参流）
```
