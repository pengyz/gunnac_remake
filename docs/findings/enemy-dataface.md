# 敌人/弹幕数据面考证（t32）— 敌对象字段 + 生成表 + t_001/t_005 重分类

> 证据等级（AGENTS.md §3）：字节+反汇编=A/B；未闭环→假设区。复现命令见 §5。
> 对照方法论 = t29 弹对象考证（docs/findings/shot-behavior.md）。

## 1. t_001 / t_005 重分类与字段切分（S1 遗留收口）

### 1.1 t_005（bank8 $ADD0-$BFFF，4656B）→ **敌人生成记录表**（已证实 A/B 级）

**字段切分：5 字节记录 `{参数×3, 行为脚本指针(2, LE, bank8 窗内)}`**（t13『5 字节组含指针字』猜测实证）：

```
rec0: bf 08 20 | e6 b3   → ptr $B3E6      rec1: 8b 1a 11 | b4 b2 → ptr $B2B4
rec2: 9b 14 11 | b4 b2   → ptr $B2B4      rec3: 87 16 10 | e6 b3 → ptr $B3E6
rec4: 87 0e 21 | 35 b2   → ptr $B235      rec5: 85 13 11 | 35 b2 → ptr $B235
```

- 指针目标 = **行为脚本流**（实录 bank8 $B2B4 = file 0x112C4：`02 79 B2 04 00 00 FE | B4 B2 00 02 79 B2 …`
  含**嵌套脚本指针**（$B2B4/$B2CA/$B2BE/$B279 自/互引）与 `FE/FC` 终止符 —— 供 bank2 解释器
  （t29 §1.3 同族：`($14),Y` 取指）消费。
- 消费侧 xref：指针字 `$B2B4` 在 t_005 本体内被引 8 次（prg 0x10DD8-0x10E34 区）= 记录间自引用 ✓。
- 三参数字段语义未定（首字节 $80-$BF 域、次字节 $08-$1A、三字节 $10-$21）→ 假设 B1（坐标/属性/时序候选）。

### 1.2 t_001（bank1 $B2A4-$BFFF，3420B）→ **对象 RAM 绑定流**（已证实 B 级）

**字段切分：变长记录 `{参数(2-3), RAM 槽指针(2, LE)}`**——指针序列**单调 +2**：
`$009D, $009F, $00A1, $00A3, $00A3, $01A5, $01A7, … $02AB…`（375 个指针字，间距 4/5 为主、偶发 8）。
- 4 字节为主 + 可变参数长度（间距 5/8 的位置 = 参数多 1-2 字节）——t13『4 字节组』修正为**变长**。
- RAM 槽指针指向 zp/$01xx/$02xx 的 16 位对（+2 递增）→ **对象槽绑定/属性表**（B 级；具体字段语义 → 假设 B2）。
- 重分类结论：两表 branch-align 77.2%/63.4%（<80%）**维持 data 分类**，但字段结构升级为上表（t13 候选→实证结构）。

## 2. 敌对象字段体系（已证实 A/B 级）—— 两套 SoA 并存

### 2.1 关卡对象系统：**$1C 间距 28 槽 SoA**（敌/玩家/道具通用）

raw 扫描 `LDA/DEC $xxxx,X` 字段访问 + t18/t25/t29 锚点合并 → 字段阵列（基址+n×$1C，n=字段号）：

> 【2026-10-12 更正（t67/N-0086）】槽寻址表述更正：**字段 k 基址 = base+k×$1C；槽 n 地址 = 字段基址+n（stride 1）**——原"对象 n×$1C 间距"系对 SoA 误释；下表字段基址清单维持（基址间距 $1C=槽数），命中样本集按正寻址重算（hit-sampling-h16.md）。

| n | 字段基址 | 已锚定语义 | 访问热度（LDA ,X） |
|---|---|---|---|
| 0 | $0400 | 类型/状态（解释器 `STA $0400,X`） | — |
| 4 | $0470 | x 亚像素（t18 N-0013 锚） | 34 |
| 5 | $048C | y 亚像素（t18 N-0014 锚） | 33 |
| 6 | $04A8 | （未定） | 70 |
| 8 | **$04E0** | x 坐标（t18 N-0011 锚：钳制 $0E-$F3） | 88 |
| 9 | **$04FC** | y 坐标（t18 N-0012 锚：钳制 $14-$DF） | 91 |
| 11 | $0534 | （未定） | 37 |
| 12 | $0550 | x 速度亚像素（t18 N-0015 锚） | — |
| 13 | $056C | x 速度整数（t18 锚；DEC 点×2） | — |
| 14 | $0588 | y 速度亚像素（t18 N-0016 锚） | — |
| 15 | $05A4 | y 速度整数（t18 锚；DEC 点×3） | 36 |

  （绝对寻址 `STA $04E0` = 槽 0 路径）→ 槽绑定语义 → 假设 B3（N-0011/12 名称维持，字段阵列语义并存）。
- HP 字段候选：$05DC/$0630/$06A0/$06BC 等 DEC 点（敌/中弹路径在 bank3/bank7）→ 假设 B4。

### 2.2 弹对象系统：**$70 间距 SoA**（t29 已证）——与 2.1 并存

t29 字段 $040E/$047E/$04EE/$055E/$05CE/$063E（间距 $70）为独立布局；两系统关系（同物异址/两类对象）
→ 假设 B5。M3 移植按两套 SoA 分别建模。

## 3. 关卡时间线/生成表定位（bank8-10 候选区）

### 已证实（B 级）

- **敌人生成记录表 = t_005**（§1.1）：每条 {参数×3, 行为脚本指针}。
- **脚本链表**（bank8 $AD00-$ADD0 = file 0x10DE0）：7 字节级记录含指针对（如 `$B2E6/$AD46`、`$B661/$AD54`
  自引对）→ **波次/脚本链候选**（结构 B 级、语义 → 假设 B6）。
- **表内自引用指针**（bank8 $ACEF 处 `AD D0` = 指向 t_005 起点）→ bank8 内存在**指针目录**
  （波次→生成表定位线索，B 级）。
- bank8 $AC80-$AD00（file 0x10CC0）：tile 索引流（`6A 6B 6C 6D 36 37…`）→ 地形/图形参数候选（C 级）。

## 4. far-call bank11 入口表归属（已证实 B 级）

| 入口 | 目标 | 归属（反汇编实证） |
|---|---|---|
| $8000 | JMP $88A3 | **系统初始化**（`LDA #$00 / STA $0E` 状态清零） |
| $8003 | JMP $88A7 | **帧处理入口**（`TXA/PHA/LDX #$07…` 寄存器保存+循环） |
| $8006 | JMP $890B | 系统例程（$890B 体，非 UI） |
| $8009 | JMP $8016 | **帧尾/标志更新**（NMI 尾调用点 t2 已证；`LDA $0E/AND #$FB`） |
| $800C | JMP $8894 | **状态标志置位**（`$0E |= $03`） |
| $800F | JMP $889B | **状态模式设置**（`$0E = ($0E&$FC)|$01`） |
| $8012 | JMP $8E2C | **硬件/变量初始化**（`STA $0318` + `$0F…`） |

- 结论：7 项全为**系统级服务例程**（初始化/帧循环/状态标志），**无 UI 专属项**——far-call (0B,0C) 单元
  = 系统服务库（B 级）。`$0E` = 游戏状态标志字节（新增 N-00xx）。
