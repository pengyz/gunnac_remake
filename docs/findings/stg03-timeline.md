## 5. 调度流差异面 + 特异挂账

- **规模**：67 记录 / +1t..+1183t（关2 为 78 记录 / +1..+933t）；尾自环 `[9]JMP $A5B0`（关末前挂起，模板恒定）。
- **ctrl 分布**：ctrl1×30 / ctrl2×19 / set10×12 / set13×2 / set14×2 / pair项×3 / jmp×1
  （关2 对照：ctrl1×33/ctrl2×20/set10×13/…同族）。
- **特异记录**：
  - @A401（+1t，首记录）`[13]reg+…[14]reg` 音画寄存器装载（关2 @AEE2 同型 ✓）；
  - @A4D2（+513t）**多 item 记录**（关2 仅 3 条多 item，本关 2 条）；
  - pair 项×3（`(type,param)` 直写槽，关2 同型 `(3A,00)` 族）。
