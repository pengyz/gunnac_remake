   attr 体地址 `($8F|3):$90` **移除 +$0F**（按 t93 翻案注）。
2. **验证环（A，§3）**：三样本 × {legacy, MODELGEO=1} × 2 跑全完成，两跑 **6/6 SAME**；

3. **期望达成（如实）**：「MODELGEO 下 gs5/gameplay ≤ 现值（1524/1265）」**达成**（=现值）；

## 1. 映射更正（A 级定谳：seed `bank15:$F08B-$F0DA`/`$F04B-$F057` 直读 + 探头 $2007 流双证）

**行体（F09A）几何 = 32B = 2 行×16 列**：

```
F09A  LDA $130,X / STA $2007   ×8      ; 8 连写
F0CA  TXA / ADC #8 / TAX / AND #$F / BNE loc_F09A   ; X+=8 双连发（AND #$F=内层步进，非地址步进）
F0D2  CPX #$20 / BEQ loc_F14F          ; X=32 收（共 2 趟）
F0D6  LDA $02 / ADC #$20 / BNE loc_F092 ; 第 2 趟地址=lo+$20（hi=$8F 不变）
```

| # | 旧实现（作废） | 更正后（本卡实现） | 证据 |
|---|---|---|---|
| 分组 | 4 组×8B：`buf[grp*8+j]`→base+grp×$20+j | **2 行×16 列**：`buf[0..16]`→base+0..15（行 R）、`buf[16..32]`→base+$20..+$2F（行 R+1 **同列**） | seed 上列逐拍 + 探头 run 形态 16B+16B、第二段=+$20（G3 §2-3） |
| 步进 | 组间 $20 ×4 组（隐含 4 行） | **+$20/行对 ×2 组**（lo 回绕 hi 不进位） | `A5 02/69 20/D0 B6` 直读 |
| attr | `($8F\|3):$90` **+$0F**（随行基校正） | `($8F\|3):$90` **无 +$0F** | `F04B A5 8F/09 03/8D 06 20/A5 90/8D 06 20` 直读（无任何 +$0F 运算） |
| geo 档语义 | geo=1 裸基+行基 $0F 校正 / geo=2 LUT 精确行基 | **不变**（行基校正量仍按档；本次只改分组/步进/attr） | §2-3「base=`$8F:$8E`(+0 或 +$0F)」 |

- 旧「4 行×8 列、组间步进 $20」系 l5-t93 §2 把 `AND #$F` 内层循环误读为地址步进（t93 翻案注，A）；
  缓冲内字段位置 (x,x+1,x+16,x+17) **不变**——2×16 下即行对 (R,R+1) 的列对 (x,x+1)（2×2 tile 块，
  连续两行，比旧 4×8 的"偶行对"解释更自洽）。
- 实现=纯函数（可单测）：`modelgeo_addr_off(i)=(i/16)*$20+(i%16)`、`modelgeo_attr_addr(hi,c)=((hi|3)<<8)|c`、
  `modelgeo_apply_row`（0 码=擦写必须生效，t243 语义不变）。

## 4. 归因（几何效应面=stg03 一处；A 级=渲染日志计数）

| 样本 | `replay_row_sets`/`row_uploads` | `pal_uploads` | MODELGEO 是否有作用面 |
|---|---|---|---|
| gs5 f3450 | 0 / **0** | 94 | **无**——v 分型路由后置位全 v=3 走调色板路，行上传不发生 ⇒ MODELGEO≡legacy 逐字节同 |
| gameplay f1260 | 0 / **0** | 70 | **无**（同上） |
| stg03 f4600 | 1503 / **1502** | 0 | **有**（opless 回退行路，行上传 1,502 次）——2×16 几何 ⇒ 58,128 |

- **gs5/gameplay「≤ 现值」达成的真因不是几何变好，而是该样本行上传面=0**（与 vtype 卡 §7-6
  「gs5 draws=0 验证力有限」同性质警示：这两样本对 MODELGEO 几何**零敏感**，等值≠几何验证通过）。
- **stg03 几何归因**：2×16 修正把 geo 路从 58,152（4×8）拉到 **58,128**（−24），再对 legacy
  58,159 领先 −31；`nt_nz` 955(legacy)→993(geo)。残差 58,128 的大头仍在非几何面：
  F1EB 命令流未接入、attr 内容=位属性合成 vs `$D3-$DA` 直拷（l5-t93 §3 嫌疑②，本卡未动）、
  HUD LUT 回退 legacy 形态、text/cmdstream 面——**几何面已按 2×16 对齐，不再是残差候选**。
- 「若 MODELGEO 全面 ≥ legacy 则报模型路不胜出」**未触发**：模型路在唯一可作用样本上胜出；
  但如实登记——**收益面仅 31 px 级、且只有 opless 回退样本可见**，模型路整体仍未证明在
  op 齐全样本（gs5/gameplay）上有任何优势（无作用面）。

## 6. 未证残留（明示）

1. **geo=1/geo=2 混合构成未单列**：stg03 1,502 次行上传里两档占比未计（旧行为不分类），逐档收益未分账。
2. **attr 内容=位属性合成（l5-t93 §3 嫌疑②）未动**：本卡只改 attr **地址**（去 +$0F），8B 内容仍 `$D3-$DA` 直拷。
3. **行基 +$0F 严格语义（B 级观察，不改）**：seed `$F083 LDA $8E/ADC #$F` 在 attr 分支（$7E≥3）
   连续 `CPY #2` 之后、其间无清 carry 指令 ⇒ 严格值为 **+$10**（+$0F+C=1）；而 `$7E==1` 裸基路无校正。
   现 geo=1「行基 +$0F」是 ROM 公式校正量的既有近似，本卡按边界不动，登记待裁。
4. gs5/gameplay 对行几何零敏感（row_uploads=0）⇒ **2×16 几何在 op 齐全样本上未获直接验证**；
   建议补一个"行上传非零 + BG 可视"样本作几何敏感锚。
