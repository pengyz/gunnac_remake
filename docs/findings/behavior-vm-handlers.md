## 3. 两随带问题定谳（A 级）

### 3.1 $EC12 RNG carry 语义（port-engineer 问①）

```
EC12  LDA $2C / ADC $2D / ADC #$01 / EOR $2B / STA $2C / INC $2D / RTS
```

- **carry 出口 = ($2C+$2D+1) 两次 ADC 的最终进位——状态依赖，非恒定**；A 返回值=新 RNG 字节。
- ⇒ $8341 jitter **x 侧双态标注保持正确**（carry∈{0,1} 两分支）；**「$EC12 恒定 carry=0」假设不成立**。

### 3.2 $8341 `SBC #7` 前 carry 来源与偏移数值面（port-engineer 问②）

链：`JSR $EC12 / TAY / AND #$0F（C 不变=$EC12 出口 carry）/ SBC #7 / ADC $4E0,X`；y 侧 `TYA/LSR×4
（C=bit3(v 低位半字节)）/ SBC #7 / ADC $4FC,X`。精确数值面：

> 【2026-10-15 补注（test-runner 预验交叉，lead 转）】**变量定义与位独立性**：设 rng 字节=v；
> x 侧索引 n=v&$0F、carry Cx=$EC12 出口进位（状态依赖）；y 侧索引 h=v>>4（高半字节）、
> carry Cy=bit3(v&$0F)（=LSR×4 出口）——**bit3（低位半字节第 4 位）与 h（高半字节）是 v 的独立位**，
> 原二行表的根因即误相关二者。**真值式**（Iverson 步函数 [·]）：
> `dy(Cy=1,h)=h−7+[h≥7]`；`dy(Cy=0,h)=h−8+[h≥8]`；x 侧同式（n/Cx 替换）——256 穷举可判 ✓。

【2026-10-15 更正（数值面分歧，port-engineer d0c5678 256 值穷举 + 本方独立复算双确认）】
原 y 两行 **bit3=1⇒+2..+9 / bit3=0⇒−8..−1** 作废——分支条件混淆（实为 bit3×h 四叉例，
漏 bit3=1∧h=7⇒**+1** 一叉，如 rng=$78 (h=7,bit3=1)：SBC 7−7=0 无借位 C_out=1 ⇒ dy=+1）。真值域：

| 侧 | 四叉例（y：Cy×h；x：Cx×n，独立位） | 净偏移 |
|---|---|---|
| x/y 同构 | C=1 ∧ 索引=0..6 | −7..−1 |
| x/y 同构 | C=1 ∧ 索引=7 | **+1**（原表漏叉） |
| x/y 同构 | C=1 ∧ 索引=8..15 | +2..+9 |
| x/y 同构 | C=0 ∧ 索引=0..7 | −8..−1 |
| x/y 同构 | C=0 ∧ 索引=8..15 | +1..+8 |

**并集（两侧行同形）：dy/dx = −8..−1 ∪ +1..+9（跳 0）**——x 侧双态分支表（原 C=1/C=0 两行）
与 y 侧真值域殊途同归；跳零结论（每帧必动 ≥1px，D4 保真）不受影响 ✓。
（y 侧 C=bit3(rng 低位半字节) 确定性 ✓ 贵方原锁无误；测试⑰ 穷举断言=真值域锁定。）

- **「±7」近似注收窄**【2026-10-15 同批更正：~~y 侧 −8..−1∪+2..+9~~ → **−8..−1∪+1..+9**】：x/y 侧同形 = **−8..−1∪+1..+9**（跳 0）；
  **0 偏移永不出现**（SBC/ADC 链跳零）⇒ 对象**每帧必动 ≥1px**——抖动动力学面（D4 保真）。
- 摆动振幅数值面以此为准；Wt-6 三角波（$5DC mod-8）为**另一驱动**（84D1 波形驱动用 $5DC 计数）。

## 4. $84D1 多相波形驱动（#18，轨迹相位机核心）

```
84D1  x/y/间隔 → $11/$10/$12 快照（$04E0/$04FC/$0534+X）
84E4  循环体（$13=相位步，$0710+X 上限）：
      Y=$072C+X+步 → $5DC+X − $857D,Y（相位阈表）<8 ⇒
        $858A,Y→$15/8597,Y→$14（子流指针对）；$85A4,Y→$05（符号标志）
        $854D,Y→$518+X、$8565,Y→$684+X；$05 bit7 → ($2B&1)^$12 相位翻转写 $534+X
        JSR $C3DF / BCS → 下一步；JSR $CC6A（运动执行）
      INC $13 / CMP $0710+X / BCC 循环
853D  恢复 $534/$4FC/$04E0 快照 / RTS
```

- **六表**：$857D（相位阈）、$858A/$8597（指针对）、$85A4（标志）、$854D/$8565（参数对）。
- **$5DC+X = Wt-6 三角波计数器**（bank05:8C8D 同字段）——**波形驱动与三角波表共享相位计数**，
  轨迹族①正弦摆动的机制候选（S4b-2 配对最终确认）。
- $072C+X=相位索引、$0710+X=循环上限（进场③/⑥ 预置 05/08）。
