## 3. 社区成果适用性修正（重要）

Plan C 原设想"社区地址直接核"→ 修正为**签名级定位**（byte-pattern 定位后换算）：
- 社区 RAM 字段（$0188/$0178/$0403 等）= **零页/绝对 RAM 地址，两版通用**（已实证 ✓，N-0200/0201）
