## 1. 改动地图（最终裁定）

| 层 | 裁定 | 证据 |
|---|---|---|
| **逻辑算法** | **未改**（签名级同码） | 钱加法器 JP `D946` vs 九班 `DBD9` 64B **仅差 2B=表地址操作数**（`B9 3C DA`→`B9 CF DC`）；VM 解释器 bank00:$844A 同址全同；装载机/生成例程 $865C 同址全同；NMI VRAM 上传链同码移位 10B |
| **数值层** | **未改** | 加数表 66B（JP $DA3C vs 九班 $DCCF）**全同**（10/30/100/…加数族） |
| 文本层 | 全换（日文→中文） | bank00/01 长 diff 段（463/590B 级）；价目面板记录同址异容（结构同为 ppu+FE/FF 记录制 ✓ 社区格式互证） |
| 指针层 | 全重定向 | bank02-07 全部差异=**2B 段 129-490 个/ bank**（16 位指针表重定向指纹，翻译挪文本必然） |
| **布局层** | bank14/15 内部移位（+659B/+10B） | 引擎例程在 bank 内搬家（钱加法器等）；**位移原因未明**（翻译支持代码注入 or 基版微差）——W 挂 |
| 字模 CHR | 大改 | chr00-07/11/12/14/15 异（中文字模），chr08-10/13 全同（背景图不变） |
| 头部 | dump 变体 | 九班 flags6=0x41 vs JP 0x40（mirroring 标志位；MMC3 运行时由 $A000 决定，行为影响存疑 W 挂） |

## 2. 核心裁定

**我们 256 任务移植的行为模型 = 两版共享的逻辑真相**（签名级等价证明）：
- 「改过的」全部落在**内容/布局层**（文本/字模/指针/银行内移位），**逻辑算法与数值未动**
- Stage A 判据（行为一致）在两版间等价成立；产品定义（九班版）维持不变是自洽的
- **坐标系桥**：九班↔JP 地址存在 bank 内偏移（bank14 +659B 等）——社区地址**不能直套**，须签名级定位（本对照即示范）；反之我方 bank:addr 标注也不可直译到社区坐标

## 3. 社区成果适用性修正（重要）

Plan C 原设想"社区地址直接核"→ 修正为**签名级定位**（byte-pattern 定位后换算）：
- 社区 RAM 字段（$0188/$0178/$0403 等）= **零页/绝对 RAM 地址，两版通用**（已实证 ✓，N-0200/0201）
- 社区 CPU 代码地址（$AB90/$F340 等）= **JP 坐标**，须按本表偏移/签名换算
- 社区文件偏移 = JP 坐标（text.csv 168 行）不可直接套九班

## 4. 遗留（W 挂）

- W-P1 bank14/15 位移原因（九班注入了什么翻译支持代码？）
- W-P2 头部 mirroring 标志差的运行时影响（$A000 谁写）
- W-P3 价目数值表直比（代码+加数表已同，推定未改）
- L2 双跑批（行为等价从签名级升执行级）——可选加强
