# 敌行为脚本机考证（t59）— $B2B4 指令集 + 解释器 + t_005 参数语义

> 方法：seed 权威反汇编（bank00 解释器）+ $B2B4 流字节级解析 + 记录装载机反查。
> 对照 t29 弹动作流方法论。⚠ 更正注记：t32/t47 的『bank2 ($14),Y 解释器』标签有误——
> **真解释器在 bank00:$844A**（bank2 区系数据表误判，同 data-island 教训族）。

## 1. 脚本 VM 指令集（A/B 级：seed 逐行 + 流字节实证）

**VM 本体 = `bank00:$844A-$8584`**（槽式字节码机，每槽一份流）：

| 指令码 | 语义 | 证据（bank00） |
|---|---|---|
| `$00` | 流结束（$19D,X:=0 退槽） | $845E/$8462 |
| `$02-$7F` | **嵌套调用**：B0=码自身；B6/BC=**子流指针（2B）**；BC=0 时为普通参数指令 | $8468 BPL $84AD（A→$B0,X）+ $84C7 装指针 |
| `$80-$FB` | **指令+3 参数**：AA=码；B0/B6/BC=参数（B6/BC 亦可为子流指针） | $846B CMP #$FC/BCC $84A9 |
| `$FC` | **X 坐标相对调整**：`ADC $A4,X`，钳 `$20-$E0`（可见区）→ **【2026-10-12 更正（t63/t62）】实为界门**：界内 [$20,$E0) 退槽/界外续行，X 不钳（字面指令流） | $8471-$8483 |
| `$FD` | **循环计数装入**：参数→$C2,X | $848B |
| `$FE` | **循环**：`DEC $C2,X`，未尽→跳 2B 指针；尽→跳过 2B 续行 | $8485-$8498 |
| `$FF` | **跳转**：2B 新流指针 → $14/$15，Y=0 | $849A-$84A7 |
| `≥$80 尾字节`（表级） | 记录表控制：$80+ = 段计数（$A3） | loader $83FA/$8438 |

**槽状态字段（zp，X=槽 0-7）**：`$A4`=X 坐标（$20-$E0 钳）、`$B0`=指令参/计数、`$B6/$BC`=子流指针、
`$C2`=循环计数、`$AA`=当前指令码；**流 PC = `$0197,X`/`$019D,X`**；输出表 = **`$0150,X`（16 槽，
CPX #$10 界）**；输出执行器 = `sub_8619`（bit 掩码分派 → $C2C6/$865C 写链）。

**$B2B4 流解析实证**（t32 实录字节按指令集解码）：

```
02 79 B2   → 调用子流 $B279      （嵌套指针 #1）
04 00 00   → 指令 $04，无子流
FE B4 B2   → 循环（$C2 计数）跳 $B2B4 ← **自环**
02 79 B2 02 00 00 FC 02 → 调用 $B279 + 指令 2 + X 调整 +2
FE CA B2   → 循环跳 $B2CA
…FE/FC 终止段…
```

嵌套指针 `$B279/$B2CA/$B2B4/$B2BE` = 子流（同 VM 格式），跳转/循环语义与 t29 弹动作流
（$890B/$892F）同构不同机（弹机=表格制，本机=字节码制）。

## 2. 记录装载机（A 级）—— 4 字节格式

**`bank00:$83F6-$8432`**（流基址 $A1/$A2，记录循环）：

```
$83F6: p0；0=表结束，≥$80=段控制
$83FC: p0 → $11；X 坐标 = p0 − $0F → $A4,X　【2026-10-12 更正（t63/t62）】实为 **p0 − $10**（SBC 前 carry=0、LSR 链置位；en-ld-1 ROM 实证）
$83FF: p1 → 拆包：bit0-2 = **槽位索引（&7，8 槽）**；bit3 = 槽停用（$19D:=0）；
       bit4-7 >> 4 = **循环计数初值**（$C2,X，0→$10）
$8422: p2/p3 = **脚本流指针** → $197,X/$19D,X
```

记录表尾：`00` 或 `$80+`（段计数 $A3）控制字节。

## 3. t_005 参数语义（B1 部分收口 + 分流更正）

- t_005（5 字节 {参数×3, 脚本指针}，t32）与本装载机（4 字节格式）**不是同一消费路径**——
  t_005 的消费方在波次链侧（t47 的 $AD00 链分段记录，字面 xref 已证伪直接寻址）。
- B1『坐标/属性/时序』裁定：**『坐标』获支持**（p0→X 坐标族，本装载机实证）；
  『属性』部分获支持（p1 packed 字段：槽位/停用/计数）；**『时序』未证**（无帧/时刻字段现身）→ W10。
- 两套记录格式并存（4B 装载机流 vs 5B t_005）→ 推测分属不同子系统（生成层/波次层）→ W11。

## 4. 敌对象字段消费点与 W7（负注）

- VM 槽字段（zp/$01xx）与 t32 `$04xx` 28 槽网格**不同 RAM 区**——本机为**生成/脚本层**
  （把记录流→输出表 $0150）；`$04xx` 网格（HP 候选 $05DC 簇/速度对/倒计时）的消费点 =
  bank3/bank7 更新例程（t32 的 DEC/LDA abs,X 站点），两层的数据流关系未证 → W12。
- **W7（同址所有权）负注**：弹槽（$048E 簇）与 VM 槽（zp）不相交；W7 维持弹/网格间问题，
  本机未新增交错证据。
