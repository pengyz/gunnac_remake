## 2. 攻击点 1 裁定："$FFF9 运行时只读"——**维持 ✓**（A 级）

- **写点扫描（全 PRG，穷举操作数对）**：`STA/STX/STY $FFF9`（`8D/8E/8C F9 FF`）、`STA $FFF9,X/Y`
  （`9D/99 F9 FF`）、RMW（`0E/2E/4E/6E/EE/CE F9 FF`）——**全部 0 命中**；9 处 xref 全是读（LDA/LDY）。
- **物理层**：`$FFF9` 落固定尾窗 bank15 ROM（`$E000-$FFFF`），MMC3 PRG-RAM 只在 `$6000-$7FFF`；
  即便有代码尝试写 ROM 也被硬件忽略（无行为效果）。故"ROM 内嵌标志、运行时只读门"定性**成立**。
- **残余（如实）**：`STA (zp),Y`/`STA (zp),X` 间接写静态不可定靶（PRG 内字节候选 35/92 处）——但靶=ROM
  时写无效，不影响本结论。自修改代码改写"读取指令"的可能未逐条排除（bank15 无 RAM 无从落盘）。
- R-D2-1（flag 实际开启效果）= 未证，同意被审遗留；改 ROM 字节实验须用户授权（D3）——被审对此的表述 ✓。
