## 2. 波次流签名对账（对照模板）

`python3 tools/wave_stream_decode.py wave 5`：

```
== STG-05 op5 波次记录流（bank9；§1.4 字段格式 23B/记录）==

-- 流 $B7D7（脚本 thr=$01A0）--

        ED3B=$00/$0F/$00 DB4C=$11 ED6C=$B7EC/$B3F9 next=$0602
        （C9 bit2=0：不跳转，链止）

-- 流 $B801（脚本 thr=$028F）--
  @B801 C9=$FB(bit0→far-call bank11:$8012 bit1→速度快照) CA=$31(bit0→$26|关末门)
        速度字节=$07 $7F=$02 写表1=$B816 写表2=$0000
        清单=$B819 count=1 types=[$A0] $D2=$00 $D1=$14/$1E

```

**差异注**：流1/流2 模板不变量全守（C9=$F2/$FB、CA bit0 臂门不变式、$D1 对全同）；差异——
① **ED6C=$B7EC/$B3F9 双非零（八关唯一非零）**——$ED6C 参数族（语义未证，S3-4 同族升级）；
② 写表非零密集：流1 写表1=$B7F9/写表2=$B7FC 双非零 + 流2 写表1=$B816（关3 同形态）；
③ 流1 CA=$70（关3 同值，bit4-6 族）；流2 CA=$31（关2/3 同值）；
④ 清单型值 $9D/$A0（不命名，S2-4 同族）；LUT=$B7CF→流1 $B7D7（+8B，Wt-3：+9/+4/+11/+4/+8）。
