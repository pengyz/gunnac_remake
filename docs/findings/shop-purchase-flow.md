## 1. 购买触发链（trigger）✅ done

**结论（A 级）**：商店主菜单位于 `bank00:$9CFC-$9D55`（R6=0/R7=1 映射窗），四个入口经
RTS 跳转表 `bank00:$9D56`（`LDA $9D57,Y/PHA / LDA $9D56,Y/PHA / RTS`，字 = 入口−1）分发：

| 光标 `$0400` | 表项（word） | 实际入口 | 菜单 |
|---|---|---|---|
| 0 | `$9D5D` | `bank00:$9D5E` | 武器（weapon） |
| 1 | `$9E85` | `bank00:$9E86` | 连射（rapid） |
| 2 | `$9F02` | `bank00:$9F03` | 发货（shipping） |
| 3 | `$A022` | `bank01:$A023` | 退出→开stage（exit） |

**按键位（A 级）**：`$16`/`$18` = 手柄状态；bit7=A（`AND #$80`），bit6=B（`AND #$40`），
bit4=Start（`AND #$10`），bit3=Up（`AND #$08` → `DEC $0400` 0 回卷 3，bank00:$9D02-$9D0F），
bit2/bit5（`AND #$24`）→ `INC $0400` 3 回卷 0（bank00:$9D11-$9D23）。
选中键 = `$16 & $D0`（A/B/Start 任一）→ `bank00:$9D3A` 分发前置，`$ED3B` 音效 $44。

**子光标（A 级）**：`$0401`=商品光标（武器菜单初始化自 `$34`，bank00:$9D6C），
`$0402`/`$0403`=发货槽索引（进发货菜单时三者同写，bank00:$9F1C-$9F22）；
横向移动 `bank00:$9E40-$9E72`（`$16` bit1/0,5 → `DEC/INC $0401` 环绕 `$10..$11` 边界）。

**trace 帧锚（A 级，`analysis/traces/shop.frames.jsonl`）**：
- f1101 `$0016:00→40`（B 按下）→ f1107 释放；f1181 `$0016:00→80`（A 按下）→ f1213 释放
  （press_len=4 的注入被场景锁存放大到 ~32 帧）。
- f1213 场景切换三联：`$0000:00→02`、`$0001:01→08`、`$0026:10→00`（$26 bit4=进店标记，
  社区 JP 场景注入条件 `ram[0]==0 && ram[1]==1 && ram[0x26]&16` 同款）；同帧 `$0400:6C→01`。
- f1230 截图 `shots/shop_f01230_probe.png` = 实机「地区-1」，即 A 触发离店开局（R-shop-7 同型）。
- `$0403` 变化帧 f206（0→08）、f913（08→02）、f1368（02→00）——与 N-0201 发货槽索引观测吻合。

**注意（B 级/未闭合）**：本 trace f1080-f1170 是**欢迎/信息页流**（截图为
「注意，收集相同导弹，导弹级增加。」→「导弹20个 上限。」，即社区 welcome 场景记录
0x2038/0x2072 同页族），A 键离店；`$0400` 在店内恒 0x6C ⇒ 9CFC 主菜单环当时**未启用**。
欢迎页流与主菜单的门控条件（首店/有款判定）本次**未取证**，留 W-NEW（假设区 §7）。

## 2. 扣减例程定位（deduction）✅ done

**结论（A 级）**：`$E0-$E6` BCD 计数器**不是**商店消费账户；商店扣减的是
**`$018E`（单字节 0..255 商店金钱）**，三处同构扣减点（价格不同）：

| 用途 | 价格 | 代码 | 字节序列 |
|---|---|---|---|
| 武器购买/升级 | 10 | `bank00:$9DE8-$9DF4` | `AD 8E 01 / C9 0A / B0 03 / 4C 5B A0 / E9 0A / 8D 8E 01` |
| 连射升级 | 6 | `bank00:$9ECD-$9ED9` | `AD 8E 01 / C9 06 / B0 03 / 4C 5B A0 / E9 06 / 8D 8E 01` |
| 发货（每发炸弹） | 4 | `bank00:$9FAB-$9FB7` | `AD 8E 01 / C9 04 / B0 03 / 4C 5B A0 / E9 04 / 8D 8E 01` |

同构模式：`LDA $18E / CMP #price / BCS 扣款 / JMP $A05B(不足) / SBC #price / STA $18E`。
扣款成功后一律 `JSR $A091`（bank01）重绘金钱显示：`LDA #$10/STA $14 / LDA #$22/STA $15 /
LDA $18E / JMP $E973` —— **「你有 ──￥N」的 N 画的是 `$018E`**（A 级）。

**第四扣减点（A 级）**：`bank02:$8FBC-$8FCB` `LDA $18E / SEC / SBC #$0A / BCC 跳过 /
STA $18E` —— 带**下溢保护**的 −10（无借位才写），随后 `LDA $0190 / JSR $9698` 授弹药；
JP 同址同字节（独立扫描互证）。

**第五类减损（A 级）**：`bank03:A39F` `LSR $018E`【2026-10-14 修（#55 必修3）：$839F=同字节别名，规范名 A39F（seed 口径）】 —— **金钱减半**（右移一位，整数截断），
前置 `JSR $ED03`（BCD 弹药扣减）→ `$018D`、音效 `$21`，属关内受击/死亡惩罚链（非商店）；
与购买扣减并列为 `$018E` 的全部减损形态（−4/−6/−10/−10 保护型/÷2）。

**显示源单锚（A 级）**：~~双锚 bank01:$A091 与 $8099 同构~~【2026-10-14 更正（#55 必修1·伪双锚）】`$8099`=`$A099` 的 $8000 窗口别名（同一 `LDA $18E` 指令勿数两次）——全 PRG 显示序列**仅 1 份**（bank01 偏移 0x0091-0x009C）。单锚 `bank01:$A091`（`LDA #$10/STA $14 /
LDA #$22/STA $15 / LDA $18E / JMP $E973`）——`$018E` 画到 PPU $2210 的数值位，
即「你有 ──￥N」的 N【2026-10-14 删（#58 必修1）：原"（两处布局各一）"=伪双锚配套主张无字节依据，与本段"仅 1 份/单锚"矛盾】。

**清零/初始化（A 级）**：`bank15:$E168` `LDA #$00 / STA $0189 / STA $0190 / STA $018E`
（商店初始化链，紧随 far-call `00 01 C3 9B` = `bank00:$9BC3` 商店 init）；

  JP 同址同字节），支出即上表；隐藏选项发放 `bank00:$9C7D-$9C86`（`$18&$33==$22` 键组合 +
  `$32` bit6 翻转门 + `$FFF9` 决定 10/30）。

## 3. 校验分支（validation）✅ done ≥2 类

**类 1 · 余额不足（A 级）**：三处扣减点共享不足出口 `bank01:$A05B`：
`JSR $A06C`（清行）→ 文本指针 `$A13D` → `JSR $A09F`（提示消息）→ `JMP $9CEC`（回主菜单环）。
不足路径**不写** `$018E`（`CMP` 不改 A，`JMP` 早退）。社区 JP 断言 `insufficient_funds`
（记录 0x1FC4）且 `cash` 不变，同构（B 级互证）。

**类 2 · 满级/满仓（A 级）**：
- 武器级封顶：`bank00:$9DCC` `LDA $33 / CMP #$07 / BCC 购买 / 否则消息 `$A408`（weapon_max）`。
- 连射级封顶：`bank00:$9E94` `LDA $3C / CMP #$04 / BCC 购买 / 否则消息 `$A4D4``。
- 发货数量封顶：`bank00:$9FC8` `CMP #$40 / BCC / LDA #$3F` —— 槽内数量 `min(qty+1, 63)`（63=0x3F）。
- 机翼（wing）状态：已购（`$32` bit7=1）→ 消息 `$A436`（wing_already_owned）；
  未满足前置（同武器 `$33>=2` 且无翼）→ 消息 `$A3B0`（wing_required）（bank00:$9D98-$9DCC）。

**消息记录 JP↔社区对照（B 级）**：不足 0x1FC4 / wing_required 0x21A0 / weapon_max 0x21C3 /
wing_already_owned 0x21E0 与 `verify_shop_runtime.py` 的 `state(...)` 断言逐一对应。
