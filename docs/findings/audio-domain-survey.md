> 范围：①APU 寄存器面普查 ②音效/音乐数据格式初探 ③audio hash golden 方案设计。

## 1. APU 寄存器面普查（A 级——写点 xref 全集）

**写点全集（bank11 三簇，A 级）**——音频驱动域=**bank11**（APU 写指令唯一所在 bank）：

| 簇 | 地址 | 寄存器族 | 语义 |
|---|---|---|---|
| 主通道 | bank11:$8173-$81E5 | $4015（使能）/ $4000-$4003,X（**pulse1/2 X 索引双通道**）/ $4008-$400B（triangle）/ $400C-$400E（noise） | 音调/包络/音量全通道写者 |
| **DMC 采样** | bank11:$8613-$8639 | $4011/$4012/$4013/$4010 + $4015 | **采样播放面**（$4012/13=采样地址/长度）——游戏语音/打击声候选 |
| 包络静音 | bank11:$88CC-$88D7 | $4000/$4004/$4008/$400C | 四通道音量/包络寄存器直写（静音/衰减簇） |

**辅助判读**：
- `$E63D` **纠偏注**（2026-10-16）：~~register write（音/PPU）~~ → 实为 **MMC3 bank-reg 写 helper**
  （`STA $01A3,Y 影子 / STY $8000（reg#）/ STA $8001（值）`）——与音频无关；
  $E649=far-call 内联参数入口（S4b-3 互证）。
- $4015 多次写（$8173/$8613/$8639 三处）=通道使能切换点（音效抢占/恢复候选）。

## 2. 数据格式初探（A/B 级分工）

**A 级（bank11 结构面）**：bank11 反汇编 6670 行（code+data 混排）。表读形态聚簇：
- **静态参数表**（bank11 内）：`$8AD5-$8AD8`（**4 字节/项连续读**=通道参数表族！）/
  $8AC4 / $89D4 / $8E67 各表读点
- **间接指针表族**：`($8),Y` ×14 + `($A),Y` ×13——**zp $8/$A 双槽指针**（音序/音符流游标）
- **iram 状态表**：$0302.Y（×3）/ $031B.Y / $0373.Y（×2）——音序器通道状态（播放头/计时）

**B 级（推断）**：
- 驱动入口=**bank-swap/far-call 进 bank11**（bank11=$8000 窗可换 bank；NMI 或帧同步音频 tick
  换入执行——外 bank 直跳面零命中，间接入口待 trace 定）
- 音乐/音效数据=**指针表→流式字节序列**（($8)/($A) 游标消费形）；$8AD5-8AD8 族=每通道 4 字节
  参数（音调高/低/包络/长度候选）——字段切分待逐字节定（C 级止步，不发明）

**假设区（C 级，不入结论）**：$8AD5 族 4 字节=（freq_lo,freq_hi,envelope,len）？——需播放 trace 佐证。

## 3. audio hash golden 方案设计（设计级，待 lead/verifier 裁）

**目标**：移植后音频行为对拍（L1-L3 差分管线之外的**音频维**）。

**方案草案（A 案：样本 hash 流）**：
1. **采集**：Mesen2 APU 输出（WAV 44.1k 或原生 1.79MHz 混音前样本）逐帧切段（60 段/秒）
2. **指纹**：每 N 帧窗口（如 1s）做 SHA-256 → **hash 序列 golden**（`data/golden/audio/<scene>.hashl`）
3. **对拍**：game-core 音频合成（Stage B 引入 APU 合成器后）同切窗 hash 比对；差异容忍=0（保真），
   可听化差异自动导出双 WAV 供人耳裁
4. **分层**：L-Audio 独立门禁（与 L4 visual 并列）；基线 ratchet 同机制（只增不降）
5. **社区吸收面**：run_mesen 脚本（社区 Soig 复现用）——同 hash 口径可对拍社区 run 的音频输出

**替代（B 案：APU 寄存器写流 hash）**：不采样，hash `$4000-$4017` 写序列（帧,reg,val 三元组流）
——**确定性更强**（不依赖混音器实现）但保真面窄（仅寄存器行为，不含 DMC 时序细节）；
**建议 A 案寄存器流先行**（Stage A 可做）+ B 案样本 hash 于 Stage B 合成器落地后补。

**【2026-10-16 lead 三裁定·定案】**：①hash 窗长=**帧窗定长 60f（1s 段）**，逐段 hash 按场景对照；②**DMC 纳入=寄存器写流一体**（写流含 DMC 寄存器事件）；DMC 样本**内容** hash 留 Stage B 合成器后；③**速率归一化=不需要**（写流=帧索引事件序列，确定性天然）。**A 案批准**=Stage A 音频 golden 正式方案，L-Audio 门禁设计稿落 [docs/spec/audio-golden.md](../spec/audio-golden.md)。

## 5. 【2026-10-16 AUD-1 收】驱动入口定谳——bank11 七入口 API 跳板（A 级）

**far-call 内联参数面**（JSR $E649 后 4B：r6,r7,lo,hi）：全 PRG 18 调用点中 **8 点 r6:=$0B
（bank11 映射）**，目标全 bank11:$80xx。**入口跳板（bank11:$8000-$8015，A 级逐指令）**：

| 入口 | 跳转 | far-call 点 | 命名 |
|---|---|---|---|
| $8000 | JMP $88A3 | 0x1E097（boot 域） | **audio init**（开机初始化） |
| $8003 | JMP $88A7 | — | （API 2，调用面未现） |
| $8006 | JMP $890B | — | （API 3，同上） |
| $8009 | JMP $8016 | — | **帧处理体**（$0E 旗 + JSR $81EF → APU 写簇 ✓ 与 §1 三簇闭合） |
| $800C | JMP $8894 | 0x1F264 | **触发口 A**（sfx/音乐） |
| $800F | JMP $889B | 0x1F2C8 | **触发口 B** |
| **$8012** | **JMP $8E2C** | **5 点**（0x9E5/0xBDE/0xF80/0xF9C/0xE912） | **音频主 tick**（帧同步消费） |

- **闭合链**：far-call（bank-swap r6:=$0B）→ 入口跳板 → $8016 帧处理 → $81EF → **§1 三簇 APU 写点**。
- r7 变化（$0C/$00）=$A000 窗伴随 bank（音频执行期伴映射面，语义挂 AUD-3 伴查）。
- **AUD-1 收** ✓；AUD-2（$8AD5 字段切分）/AUD-3（指针表全集）续。
