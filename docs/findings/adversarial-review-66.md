## 1. 独立重导（ROM 直读，不采信被审更正语；顺带证伪"修复引入新矛盾"）

### 1.1 `E18C` 网格清零循环（AR63-5 更正语真伪）

```python
rom=...; b15 = lambda a: 0x10 + a + 0x10000   # bank15 固定 $C000-$FFFF（锚点 sub_ECBF 同法已验）
print(rom[b15(0xE189):b15(0xE18C)+15].hex(' '))
# => a9 00 aa 9d 00 04 9d 00 05 9d 00 06 9d fe 06 ca d0 f1
#    LDA#0 / TAX / STA $400,X / STA $500,X / STA $600,X / STA $6FE,X / DEX / BNE -15
```

- 入口 `A9 00 AA`（LDA #0 / TAX）⇒ X=0 起，`DEX/BNE` 回绕走 **X=0..255 全 256 值各写一次**。
- 四页写点 `$400,X / $500,X / $600,X / $6FE,X` ⇒ 实清 **`$0400-$06FF` + `$06FE-$07FD`**；
  **`$07FE-$07FF` 不在任何写基址内、不清**。
- ⇒ 更正语"网格范围已正 **$6FE-$7FD**"（`$7FE-$7FF` 不清）**逐字节成立** ✓；
  旧主张"$06FE-$07FF 全清"确系错误（末 2 字节虚增），"28 槽全灭"非 E18C 粒度（循环=字节四页非槽）✓。

### 1.2 `E3BB` 入口减半变换（AR63-7 更正语真伪）

```python
off = 0x10 + 0xE3B9 + 0x10000   # = 0x1E3C9
print(rom[off:off+22].hex(' '))
# => a2 05 bd 7a 01 48 29 c0 85 04 68 4a 29 1f 05 04 9d 7a 01 ca 10 ec
#    LDX#5 / LDA $17A,X / PHA / AND #$C0 / STA $04 / PLA / LSR A / AND #$1F / ORA $04 / STA $17A,X / DEX / BPL
```

- 逐位：`$04 := v&0xC0`（bit7-6 保留）；`LSR A`⇒ bit0→C 丢弃、bit5→bit4；`AND #$1F` 取移后低 5 位；`ORA $04`
  ⇒ **`(v&0xC0)|((v>>1)&0x1F)`**。
- ⇒ 更正语"**6 位数量÷2 存 5 位（丢 bit0、bit5→bit4）**"**逐位成立** ✓；旧主张"低 5 位减半（bit5 丢）"
  双错（bit5 未丢而降位保留、丢的是 bit0）✓ 删除线得当。
