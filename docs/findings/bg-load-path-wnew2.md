# W-NEW2 BG 装载路径取证（t100）— 观测模型定谳 + 调色板绑定解锁

> ①BG 装载例程 = 行地址 LUT 通道（`$EBF4`）；②调色板装载路径定谳（**t99 路由 b 解锁**）；
> ③W37 部分收。方法：静态例程反查 + probe 写流（扩窗 $161-$16F）。

## 1. BG 装载路径（①）—— **行地址 LUT 通道定谳（A 级）**

**装载例程（bank00:$80F9-$8114）**：

```
$80F9: LDA $8D / ASL / TAY            ; $8D = 行/段索引
$80FE: AND #$1C / ASL / ORA #$C0 / STA $90   ; $90 = 属性行基址（$C0 族）
$8105: LDA $EBF4,Y / STA $8E          ; ★$8E ← LUT 低字节
$810A: LDA $EBF5,Y / STA $8F          ; ★$8F ← LUT 高字节（C 置位时 ORA #8）
```

**`$EBF4` 行地址 LUT（bank14，16 项）实录**：

```
[0]$2000 [1]$2040 [2]$2080 [3]$20C0 … [12]$2300 [13]$2340 [14]$2380 [15]$2CA5
```

= **nametable 行基址（$2000+$40n，64B 行距）**，[15]=$2CA5 = 表尾/属性区特例。

**通道模型**：`$8D` 行索引 → `$EBF4` LUT → `$8E/$8F`（+NMI `$0F` 偏移、组内 +$20）→
行缓冲 `$130-14F`（bridge 填充）→ **NMI `$2007`**。属性行 `$90` 族 + `$D3-$DA` 位属性并行。

- t97 地址序列（$8E $40 步进族/8 帧行节律）与本 LUT **完全吻合**（$40=行距 ✓）——跨任务互证。
- **『未观测机制』不存在**：nametable 装载 = 全程已观测通道（bridge→行缓冲→$2007），无 DMA/暗通道。

## 2. 调色板装载路径（②）—— **定谳（t99 路由 b 解锁）**

**装载例程（bank00:$8870-$88AA）**：

```
$8870/$8882/$888D: 数据流指针 ← ($8844)/($88DA)/($89xx) 族（调色板数据流）
$8877: LDA #$37 → $161/$168/$169（固定色）
$8895-$88A7: 逐字节填 $161-$169；流尾字节 ≥$80 → `$160 |= 码`（挂起类型）
```

**probe 写流实证（扩窗 $161-$16F，3,346 事件 / 143 帧）**：

| 证据 | 值 |
|---|---|
| 地址分布 | $0161-$016D 全族（$161 主写 607 次） |
| **色值流** | **$0F×1180、$30×401、$00×304、$10×229、$20×151、$18×90、$06/$07…**（NES 调色板索引 ✓ t99 真值集加载侧） |
| 内容帧相关 | f1200/1204/1207-1209/1213-1214/1218-1219 —— **与 BG 装载批 f1204-1207 同窗** ✓ |

- **t99『$161-$167 调色板源 0 写事件之谜』解**：t94 probe 窗为 `0130-0160`（**$161+ 在窗外**）
  —— 纯采样窗缺 口，非装载路径绕行 ✓（W-NEW2 阻塞清除）。
- **调色板绑定像素级证明（路由 b）解锁**：色值流（$161-16D 写值）↔ `$3F00` 上传 ↔ 屏幕色
  的绑定链 = 全程可观测（$2006 I/O 盲区由 $8E/$8F 源 + NMI 模型绕过）。

## 3. W37 部分收（③）

`$8E/$8F` 双写 = **每帧两次行更新调用**（装载例程每次单写；观测双写 = 双调用/帧）——
语义候选（上下半行/滚动双步进）→ W39。

## 4. 观测模型总表（L4 收敛断言面）

| 层 | 通道 | 状态 |
|---|---|---|
| BG nametable | $8D → $EBF4 LUT → $8E/$8F → 行缓冲 → NMI $2007 | ✅ 全链已观测 |
| 属性 | $90（$C0 族）+ $D3-$DA → NMI 支路 | ✅（t64/t94） |
| **调色板** | 数据流 → $161-169 → $160 |= → NMI $F105 → $3F00/$3F10 | ✅ **本任务闭合** |
| 地址相位 | $8E/$8F 写流（NMI 时值） | ✅（t97） |
