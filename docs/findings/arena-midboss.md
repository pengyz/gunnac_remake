## 1. 敌弹 RAM 布局（W-tas-1）—— 定谳

### 1.1 结论表（A 级）

| 项 | 结论 | 证据 |
|---|---|---|
| **敌弹归属** | **同一弹网格**（20+12 槽共享池），**非独立表**、**非 28 槽对象网格** | 生成写点全在 `$040E+Y` 六数组（下表）；对象网格 type 数组 `$0400+n` 无弹写点 |
| **弹网格六数组**（SoA，同槽偏移 Y） | `$040E+Y`=寿命/动作倒数、`$047E+Y`=动作流指针、`$04EE+Y`=x、`$055E+Y`=y、`$05CE+Y`=运动指令码、`$063E+Y`=**型码** | 自机生成 bank3:$A20F-$A22B、敌弹生成 bank3:$ABEF-$AC11、脚本机 bank2:$87B3-$8812（逐指令） |
| **自机弹槽位**（分配器 bank2:$888D-$88BA） | 4 组×5：`$80-$84`/`$9C-$A0`/`$B8-$BC`/`$D4-$D8`（组距 $1C，空槽判 `$040E,Y==0`，首适应） | L2 四用例三方全等（shot-slot-geometry §2）+ 本轮逐指令复核 |

### 1.2 敌弹生成例程（发射点/初速写点，A 级）

`bank3:$ABE6-$AC16`（type `$02/$03` 系行为体 tick 内的齐射段；逐指令本轮反汇编）：

```
$ABE6  LDA #$02 / STA $11          ; 每 burst 2 发
$ABEA  JSR $AC42                   ; ★分配敌弹槽 → Y（carry=满跳过）
$ABEF  LDA $04FC,X / STA $055E,Y   ; ★发射点 y = 发射者 y
$ABF5  LDA $04E0,X / STA $04EE,Y   ; ★发射点 x = 发射者 x
$ABFB  LDA #$80 / STA $063E,Y      ; ★型码 = $80（敌弹标志）
$AC00  LDA #$01 / STA $040E,Y      ; ★占用=1（寿命/动作倒数起始）
$AC05  INC $072C,X                 ; 发射者在途计数 +1
$AC08  LDA $11 / LSR / LDA #$01 / BCC / LDA #$07
$AC11  STA $047E,Y                 ; ★动作流指针 = $01 或 $07（2 发交替）
$AC14  DEC $11 / BNE $ABEA
```

- **初速 = 动作流 `$01/$07` 的语义展开**：脚本机 bank2:$87B3 按 `$890B,Y`（动作流）→ `$05CE,X`（运动码）→
  `$88BB/$88CF` 16 向速度 LUT 分量加 `$04EE,X/$055E,X`；`$892F,Y` 为动作时长（0=跳转取新指针）。
  —— 弹速表 bank5:$AC5F 三角波（Wt-6）与此链的关系本轮未接（见 §6）。
- **寿命**：`$040E+Y` 逐帧 DEC（fire-hold 逐帧实测 255→…→0 释放，A 级）；归零/出界 → `bank2:$87FD` 回收：
  `$072E,型` 在途计数 −1（BMI 型=`$80` 跳过回加）+ `$040E,Y:=0` 释放。
- 对照自机生成（bank3:$A1FD-$A22B）：`$055E,Y←$04FC`（玩家 y）、`$04EE,Y←$04E0`（玩家 x）、`$063E,Y←X`（0..5）、
  `$040E,Y:=1`、`$047E,Y←$0766,X`（武器配置流脚本参）——**两族共用同一六数组，仅型码/槽位子集/脚本参源不同**。

### 1.3 运行时签名字节（A 级，快照可重导）

- v2-diag 敌弹独占槽（`$85/$A1/$BD/$D9`）活跃 197 点：**型码 `$80` 197/197**，脚本参 `$0D` 主导、运动码 `$0C`——

## 2. 自机弹命中判定（关键）—— 定谳 + 三解裁定

### 2.1 统一命中框表（A 级；W24 阅读端本轮收口）

**框表**（21 条/帧，索引 `$74`，弹/敌/玩家同表注册）：

| 数组 | 语义 | 注册写点 |
|---|---|---|
| `$0780` | 左 | 弹侧 bank2:$884D `x−4`（钳 0）/ 敌侧 bank14:$D52F `$70` |
| `$0795` | 右 | 弹侧 `$885B` `x+3`（钳 FF）/ 敌侧 `$D534` `$71` |
| `$07AA` | 上 | 弹侧 `$8868` `y−5`（钳 0）/ 敌侧 `$D525` `$72` |
| `$07BF` | 下 | 弹侧 `$8875` `y+5`（钳 FF）/ 敌侧 `$D52A` `$73` |
| `$07D4` | **归属**（弹=槽偏移 bit7 置；对象=槽号 0..27） | `$8881 TXA` / `$D539 TXA` |
| `$07E9` | **属性掩码**（弹侧常量 **`$30`**；敌侧 `$04C4,X & $F0`） | `$8885 LDA #$30` / `$D517` |

- **弹命中框 = 7×10px**（x−4..x+3，y−5..y+5）——hit-sampling-h16 样本包络（|dx|≤9,|dy|≤15）与之相容（样本=质心距）。
- 敌侧框形：`$0518,X`（形索引）→ `$97BA/$9812` 表 = 4 字节 (左,右,上,下) 偏移组，`$79` = 子框数（多子框/型）；
  `$0534,X` 翻转位（bit6=水平镜像、bit7=垂直，`$D548` 内 `BIT $04`/BVC/BPL 实现交换+取补）；偏移叠加 `$04E0,X/$04FC,X`（钳 0/$FF）。

**重叠判定阅读端（W24 死结打开，A 级）** —— 两遍扫描，均在 bank14：

```
阅读端 A bank14:$D78B-$D7EC（"我打到了谁"）：

  全无命中：DEC $79 子框循环 → CLC
阅读端 B bank14:$D7ED-$D846（"我打到了玩家"）：
  同 4 边+属性测试，但 $07D3,Y≠0（归属≠slot0）即跳过 —— 只与玩家框碰撞；命中 SEC（$6D=条目）
```

## 5. bot 判据输出（B2 v4 修正输入面）

### 5.1 瞄准修正量计算式（命中判定已解 ⇒ 可闭环节）

```
实时读点（RAM 直读，均有 A 级地址）：
  boss:    x_b = $04FB, y_b = $0517, HP = $064B, 形 = $0533
  玩家:    x_p = $04E0, y_p = $04FC
  召唤物:  slots 22..26 → x=$04E0+n, y=$04FC+n, type=$0400+n（活动判据 type≠0）
  敌弹:    弹网格敌弹槽 $85/$A1/$BD/$D9（+共享 $83/$84/$9F/$A0/$BB/$BC/$D7/$D8）：
           state=$040E+Y≠0 且 型码 $063E+Y=$80 → x=$04EE+Y, y=$055E+Y

瞄准容差（弹框 7×10 + 敌框形表）：
  tol_x = 4（弹框半宽 x−4..x+3）+ box_half_w(boss 形 $27 ← $97BA/$9812 表)
  命中条件（弹框 ∩ boss 框）：|x_shot − x_b| ≤ tol_x 且 弹道 y 段与 boss 框相交
  ⇒ 发射决策：|x_p − x_b| ≤ tol_x 且 弹道直线 (x_p..x_b, y_p..y_b) 不穿越任何召唤物框
```

### 5.2 伤害预算与节奏

- **7 发命中 = 击杀**（14 HP ÷ 2）；实测基线 1 发/1500f ⇒ v4 需 ≥7× 命中率（对准跟随 + 清障后可达）。
- 弹一框一伤（`$D7DA` 清框）⇒ **每发必须直通 boss**；召唤物带（y100-200）是弹 sink——优先 x 对准且召唤物不在弹道，
  或等召唤物离开 x 走廊。炸弹（R-tas-2）只作 128f 死亡窗后置/被围应急，**非通关必要**。
- 进度判据（闭环可读）：**HP `$064B` 单调递减**即命中计分——bot 每发后读 HP 差分 = 命中确认（0 差分=重瞄）。

### 5.3 复活重定位判据（B2 v3 教训闭合）

- 死亡窗检测：`pstate` 15→1 跃变帧 + 残机 `$018x` 递减 + 位置冻结；复活帧 = pstate 回 1 且 `$04E0/$04FC` 写入新值。
- **重定位动作**：复活即读 `x_b=$04FB`（boss 循徊中）→ 目标 `x_p := x_b`（±tol_x），y 保持底带 208-223（v3 相位带）——
  开环轨不可观测复活 ⇒ v4 必须 `record-to-scenario` 闭环（bot 在复活帧段记录 → 回放复核）或 C2 save-state 段级接力。
- 复活点 (128,160) 落在 boss 循徊带（B2 v3）⇒ 复活后 1-2s 内必先横移出带再对准，否则接触死循环。

### 5.4 避让面（W-tas-1 消解后升级）

- 敌弹可精确识别（型码 `$80` + 槽位集）⇒ 避让 margin 从"候选 12px+4px"升级为**逐弹实算**：
  每敌弹框 = (x−4..x+3, y−5..y+5)，玩家框（W15 残余，样本 |dx|≤12,|dy|≤12）⇒ 逃逸走廊 = 逐弹框并集补集；
  弹速 = 动作流 `$01/$07` 展开（`$88BB/$88CF` LUT）可前瞻 8-16f（Wt-6 三角波接线前先用 LUT 直读）。
