# $0160 行完成 flag 语义（t131 行完成判定，2026-10-17）

> 指派：flag 语义 ROM 侧——$0160 写点全谱+v 值语义+行完成条件。A 级定谳交 port 实装。

## 1. $0160 写点全谱（A 级）

| 域 | 写点 | 形态 |
|---|---|---|
| bank15 | **$EC42**（`STA $0160/RTS`）| **setter 尾 helper**（落穿到达） |
| bank15 | **$ED68**（`STA $0160/RTS`）| **setter 尾 helper 二** |
| bank00 | $827A/$88A3/$900A/$904B | 直写（状态设置点） |
| bank05 | $853F/$85C6/$87EB | 直写（状态设置点） |

**状态字段族注**：$0160 邻域=**行/文本状态组**（$0160/$0161/$0162/$0165/$0168）——
bank15:$EC2C `LSR A/TAY/LDA $EC46,Y → $0161/$0162/$0165/$0168` **参数分发表 $EC46**
（类型码×(A/2) 索引）——$0161 族=行参数组。

## 2. v 值语义（A 级，F0DC 判定体）

```
F0DC  LDA $0160 / BEQ $F14E     ; **0=空/未激活**（跳过行处理）
F0E1  CMP #$02 / BEQ $F0F7     ; **2=完成/特定型**（专属分支 $F0F7）
F0E5  LDY #$00 …               ; **其余值（1/3+）=行处理中**
```

- v 值谱：**0=空 | 2=完成型 | 其余=处理中**（1/3+ 细分待 F0F7/F0E5 支体续——B 级初谱）。
- $EC46 分发表字节直读（类型码源）；$0161 族=每行参数（行址/计数候选）。

## 3. 行完成条件（A 级，行循环体 F0C8-F0DA）

- **行尾码=$20**（`CPX #$20/BEQ $F14F`——**空格/终止码=行完成路**）；
- **低半字节计数**（`AND #$0F/BNE`——行内字计数）；
- **行宽=32**（`ADC #$20` 步进——32 字符/行）；
- 完成判定=**三元**（$0160==2 或 行尾码 $20 到达+计数归）——port 行完成判定可按
  「flag 状态 + 行尾码 + 计数」三件套接。

**挂**：$EC46 表全字节+F0F7 支体（完成型 2 的处置）+bank00/05 直写点语境——
