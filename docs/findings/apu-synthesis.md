# APU 合成语义（D1 深化，2026-10-18——Audio trait PCM 真实现支撑）

> 前链：[audio-domain-survey.md](audio-domain-survey.md)（AUD-1/2/3）——本档=参数→寄存器合成规则。
> 纪律：已证参数表驱动，不发明；A/B 分级。

## 1. 合成链总图（A 级）

```
$8AD5 族通道参数表（AUD-2 字段切分）
  → 状态槽（$032B/$03E3/$0343/$03DB…）
  → 合成变换（音调合成式/音色提取）
  → 寄存器影子（$0309+X 族/三角 $0311-14/噪 $0315+$0317）
  → $4000+X 直写（bank11:818C-81E5 APU 写簇）
```

## 2. 合成规则五线（A 级逐指令）

| # | 面 | 规则 | 证据 |
|---|---|---|---|
| 1 | **音调合成式** | `$03E3 + transpose($0A) → AND #$0F（**16 音阶**）+ $80 八度旗（BPL 后 ORA）` | bank11:83A9-83BA |
| 2 | **noise 周期** | `$0317（=音调合成产物）→ **$400E**`（noise period 直写） | bank11:81E2-81E5 |
| 3 | **音色（duty）** | `$8AD7 高 2 位（&$60→ROL）→ pulse $4000 bits 7-6`（**duty 4 形**） | bank11:84A3-84A9（AUD-2 同源） |
| 4 | **pulse 影子族** | `$0309+X → $4000+X`（X=4→0 倒序循环：控制/扫频/周期低/高）；`$030A+X BMI→#$08` 扫频特判 | bank11:8189-819C |
| 5 | **triangle 三字段** | `$0311→$4008（线性计数）/$0313→$400A（周期低）/$0314→$400B（周期高+长度）`；$0311 有 `$30/$80/$CF` 变换 | bank11:8179-81D9 |

## 3. 参数→语义对照（port PCM 面输入）

| $8ADx 字段 | 合成语义 | 级 |
|---|---|---|
| $8AD7 低 5 位 | **音调枚举**（$10 阈值+$6F 补偿→$03E3；+transpose→16 音阶+八度旗） | A |
| $8AD7 高 2 位 | **音色/duty**（$60 mask→ROL→$4000 7-6 位） | A |
| $8AD5 | 通道状态→$032B（包络/音量源链注） | A（链）/B（包络位形细分） |
| $8AD6/$8AD8 | 字段 2/4（长度/扫频源候选） | B |

**noise/音调实证**（A 级）：16 音阶（$0F 掩码）+八度（$80 旗）+transpose（$0A 加法）=**三参数音高模型**；
**duty 4 形**（00/01/10/11→12.5/25/50/75%）=音色维。

## 4. 残项（挂）

- pulse 周期 11 位换算（$0309+X 族的周期低/高合成源——$0343/$03DB 写者族待续）；
- 包络位形细分（$8AD5→$032B→$4000 低 4 位链）；
- 长度计数器表（$4003/$400B 高 3 位族）。
