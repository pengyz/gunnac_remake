## 1. W12 桥定谳 —— **前提证伪：VM = BG/地形脚本机，输出不进 $04xx 网格**

**桥本体 = `bank00:$85A0-$8618`**（VM 输出表消费回路，seed 实证）：

```
$85A0: LDA $7D / JSR $E62E            ; bank 切换
$85A5: LDA #$0E / STA $13             ; 输出偏移（步进 −2，8 次）
$85AF: LDA $150,X                     ; ★读 VM 输出表（图案索引）
$85B2: ASL/ROL 5/ASL/ROL 5/ADC $150,X ; 索引 ×3
$85C0: ADC $7A / STA $04              ; ★（$7A/$7B 基址 + ×3）→ 记录指针
$85CE: LDA ($04),Y / STA $130,X       ; ★字段1 → $130,X
$85D4: → STA $131,X                   ; 字段2
$85DA: → STA $140,X                   ; 字段3
$85E0: → STA $141,X                   ; 字段4
$85E6: → AND #7 / STA $07             ; 字段5（低 3 位）
$85F9: LDA $D3,X / AND $E9D2,Y …      ; ★位属性写 $D3,X（掩码表 $E9D2/$E9D6/$E9DA）
```

| 裁定 | 内容 | 级 |
|---|---|---|
| **字段映射**：`$150,X` = 图案索引（×3 查 `$7A/$7B` 表 → 5 字节记录 = 4 字段 + 标志字节） | A |
| **搬运目标**：`$0130/$0131/$0140/$0141`（缓冲族）+ `$07` 标志 + `$D3,X` 位属性（掩码合成） | A |
| **W12 前提证伪**：VM 输出**不进 $04xx 28 槽网格**——三族 RAM（zp VM 槽 / $0130-$0140 缓冲 / $04xx 网格）分层；VM = **BG/地形脚本机**（生成层网格由 t_005/记录装载机侧生成，两层无直接搬运例程） | A |
| **S4 顺带收口**：t32 地形 tile 流（$AC80）/波次链 BG 面的消费链 = 本 VM 机（指令集 t59 已解 + 本桥）——S4『消费例程未定位』**收口为本链** | B |
| 同步时机：VM 槽循环（$844A-$8588，6 槽/帧）后立即桥接（$858F 起，8 输出/帧） | A |

## 2. H-16 命中/清除链（部分收口 + 候选实录）

### 2.1 敌清除链——寿命/倒数清除段（已证 A 级）

**`bank03:$A479-$A4DD`**（对象到期/退出序列）：

```
$A479: DEC $6F4,X / BEQ 到期          ; ★$6F4,X = 到期倒数字段
$A482: 到期：$518,X:=0 / $684,X:=$F1 / $5A4,X:=$FF / $614,X:=$10
$A496: JSR $CB4F → Y 坐标 −$10 位移退出（BCC→$A4B6 钳 4 + JSR $CDBF）
```

- 语义：倒数字段耗尽 → 对象转入**退场动画**（上移出屏 + 字段复位）——非命中触发的『自然清除』路径 ✓。
- 命中触发清除（HP 归零→释放）：静态未定位本轮（$05DC/$0630 等 DEC 簇的命中上下文未逐一分解）→ 残余 W14。

### 2.2 玩家受击判定（H-16 本体）——候选实录（C→B 级）

死亡事件起点（respawn-window t40 双事件）**逐帧 RAM 差分**：

| 帧跃变 | 亮点变化（zp） | iram 亮点 |
|---|---|---|
| E1 f1830→1831 | **`$65`: 0→$80**（bit7 翻转！）、`$52/$54`: 20/4→240/68 | $0393-$0397 五字节同步 +$88 |
| E2 f2045→2046 | **`$65`: $80→0**（翻回）、`$52/$54`: 240/68→20/4 | $0393-$0397 同步变化 |

- **`$65` bit7 = 死亡/重生事件状态候选**（双事件交替翻转）→ N-00xx `_todo_death_state_flag`（C→B）。
- `$52/$54` 对 = 事件动画相位候选（两值交替）。
- 触发例程（判定盒/比较链）**未定位**（移动例程入口无门；冻结发生在调用层）→ W15；
  判定盒尺寸/无敌窗口 → H-16 维持未证域（R-enemy 命中段**升格判据不足，如实报**）。

```bash
import json
rows={}
for line in open('analysis/traces/respawn-window.frames.jsonl'):
    r=json.loads(line); d=r['w']
    rows[r['f']]=(bytes.fromhex(d['zp']),bytes.fromhex(d['iram']))
for a,b in ((1830,1831),(2045,2046)):
    z1,i1=rows[a]; z2,i2=rows[b]
    print(a,b,'zp:',[(hex(i),z1[i],z2[i]) for i in range(256) if z1[i]!=z2[i]][:8])
PY
```
