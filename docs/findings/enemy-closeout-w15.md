# enemy 收尾：W15 触发例程反查 + spawn 帧表正寻址复核（t72）

> 含 **spawn 节律更正**（16→8-10 帧，旧口径系寻址伪影）与 **W9 收口**（计数回收闭环）。

## 1. W15 —— **命中框注册系统定位**（A 级）+ 阅读端残缺

### 1.1 弹侧框注册（bank2:$8847-$8880，A 级）

```
$8847: LDY $74 / CPY #$15 / BCS 满      ; 框表索引 $74（上限 21=0x15 条）
$884D: $04EE,X − 4 → $0780,Y            ; ★框左（钳 0）
$885B: $04EE,X + 3 → $0795,Y            ; ★框右（钳 FF）
$8868: $055E,X − 5 → $07AA,Y            ; ★框上（钳 0）
$8875: $055E,X + 5 → …                  ; ★框下（+5，对称）
```

→ **弹命中框 = 7×10 px**（X−4..X+3，Y−5..Y+5）——t66 包络候选（|dx|≤9,|dy|≤15）与之相容
（样本为质心距；框=边沿重叠判定）。

### 1.2 敌侧框注册（bank14:$D510-$D547，A 级）

```
$D517: $04C4,X & $F0 → $07E9,Y          ; 敌属性掩码
$D525: $72 → $07AA,Y（上）  $D52A: $73 → $07BF,Y（下）
$D52F: $70 → $0780,Y（左）  $D534: $71 → $0795,Y（右）
$D539: TXA → $07D4,Y                    ; ★归属槽号
$D53D: INC $74                          ; 条目推进
```

**统一框表**：`$0780`（左）/`$0795`（右）/`$07AA`（上）/`$07BF`（下）/`$07D4`（归属槽）/`$07E9`（属性），
21 条/帧，弹/敌同表注册——**碰撞模型 = 框表两两重叠判定**（B 级推定）。

### 1.3 残缺（如实）

- **重叠判定阅读端未定位**（全索引形式扫描 0 命中 → 间接寻址）→ W24。
- 玩家受击判定盒（W15 本体）：玩家框注册点未单列（疑同表以槽 0/专属条目注册）→ W15 残余。
- `zp $65` 写点扫描：唯一 `STA $65,X` 命中 = bank11:$9D68 **data-island 第六例**（邻接伪命中）；
  W16（死亡状态候选）写者仍未定位。

## 2. 弹生命周期回收（W9 收口，A 级）

**bank2:$87FD-$8812**（弹退出路径）：

```
$87FD: LDY $063E,X（弹型）/ BMI 清槽
$8802: LDA $072E,Y / BEQ / SEC / SBC #$01 / STA $072E,Y   ; ★计数回收（在途数 −1）
$880D: LDA #$00 / STA $040E,X / RTS                        ; 槽释放
```

→ `$072E,X` 语义定谳 = **每型在途弹计数**（生成 +1 / 消亡 −1），`$074A,Y` = **在途上限**（阈值比较）；
t52 W9『计数复位闭环』**收口**（非复位例程而是配对增减）。

## 3. spawn 帧表正寻址重采（②）—— **不一致 → 更正**

| 口径 | 事件数 | 节律 | 突发簇 |

| 旧（base+n×$1C 误址，t47/t40） | 104 | **16 帧**三段连发 | f1301/f1787/f1916 |
| **新（正寻址 $0400+n）** | **112 激活 / 110 释放** | **8-10 帧主导**（Δ10×19、Δ8×15、Δ7×6…） | 1459/1468/1596/1675/1724/1852/1891/1980/2131/2172/2201 |

- **『16 帧周期』系误址伪影**（对 t47 Wv-3/t40 spawn 节律的更正）；真实节律 = **8-10 帧连发 + 突发簇**。
- t47 的 f1301/f1787/f1916 簇点**未复现**（新簇点见表）——相关 spawn 时刻结论按证伪更正流程处理。
