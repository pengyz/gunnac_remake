# W21 tile 流格式定谳（t76）— $97 指令流族破局 + 关卡脚本体系链

> 破局路径：VM 生成侧反查（装载基址链）→ 发现 **$97 指令流解释器族** → t47 波次链 =
> 其 6 字节记录流（bank8 指针吻合）→ **W21 格式族收口 + Wv-2 收口**。

## 1. 关卡脚本体系链（A 级架构发现）

**四层流处理链（bank00，seed 实证）**：

```
($88/$89) 根流（阶段脚本目录）
   ↓ $8205: LDA ($88),Y → $97/$98（流基址装载）
($97/$98) 指令流解释器（$8308-$8388）
   ├─ 记录 {f1,f2,f3,f4}：f2<$80 → 4B（(f3,f4)=指针对 $99/$9A）
   ├─ f2=$80-$FB → 6B 记录 {f1,f2,f3,f4,f5,f6}：(f5,f6)=**bank8 流指针**（$99/$9A）
   ├─ f2=$FC → ★装载 ($A1) 记录基址（$8348: $12/A → $A1/$A2）
   ├─ f2=$FD → ★循环计数装入（f1 → $9D，$833B）
   ├─ f2=$FE → 循环（DEC $9D，未尽跳）
   └─ f2=$FF → 跳转（新流指针 $12/A → $97/$98）
   ↓ $FC 装载的 ($A1) 基址
($A1) 4B 记录装载机（$83F6：{p0→X 坐标=p0−$10, p1 packed 槽位/停用/计数, p2/p3=脚本指针}）
   ↓ 脚本指针
VM 槽字节码机（$844A：t59 指令集）→ $0150 输出 → 桥（$85A0）→ BG 缓冲（t64）
```

## 2. W21 定谳 —— **格式族收口**（t47 波次链 = $97 解释器 6B 记录流，A 级）

**t47 波次链字节按 $97 格式解码（决定性验证）**：

```
46 AD 03 00 E6 B2   → f2=$AD（$80-$FB 族）→ 6B 记录，(f5,f6)=$B2E6 ★bank8 指针吻合
10 FD 08 00 61 B6   → f2=$FD → 循环计数 $9D=$10（=16）★Wv-2 收口
00 FE …             → f2=$FE 循环 / $FF 跳转（t47 的 FE/FF 终止符实为控制字节！）
```

| 裁定 | 内容 | 级 |
|---|---|---|
| **波次链/脚本流格式 = $97 解释器记录流**（4B/6B + $FC/$FD/$FE/$FF 控制字节） | A |
| t47『FE=段末/FF=链末』**重释**：FE/FF = 解释器**循环/跳转控制字节**（非纯终止符） | A |
| **Wv-2（FD 标记）收口**：`$FD` = **循环计数装入**（操作数→$9D）——t47 段参数对『10 FD/08 FD』= 计数命令 | A |
| Wv-1（段参数语义）部分收口：6B 记录 f3/f4 = 参数对（坐标/属性族），f5/f6 = 子流指针——『时刻』读维持证伪 | B |
| **$AC80 本体**：格式族已定（同族候选），但 4B/6B 对齐试切分仍不稳 → **字节级归属残余**（W21′） | C |
| t69『5B 试切分』系**错误格式假设**（桥 5B 记录是另一张表=$7A/$7B 图案表）——本条重释 | A |

## 3. ② B-STG 子格准入解锁评估（报 captain，登记归 spec-writer）

- **B-STG-xx-EN/BOSS 子格证据准入**：格式族已定谳（$97 记录流 + VM 指令集 + 桥链全通）——
  以 **VM 指令流为规格对象**（③替代路径）即可取证，**$AC80 字节级归属不构成阻塞** →

- Wv-2 已收口（§2）；Wv-1 『时刻』维持证伪。
