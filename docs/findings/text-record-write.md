# 文本记录写点取证（t117）— 装配链定谳（重试 #6 证据钥匙）

> ①写点链四段定谳（流指针→地址合成→预算门→寄存器写）；②装配源部分收；③W46 顺带收。

## 1. 文本记录运行时装配链（①）—— **四段定谳（A 级）**

```
[流指针] bank00:$96CE-$96D4：$2F/$30 → $12/$13（文本流基址）
   ↓
[取指/地址合成] bank00:$96D8-$9708：
   字节 ≥$80：$FE=终止/继续、其他→$0180 标志
   字节 $20-$7F：数据（$04 复用）+ AND #$1F / ADC $14 / ORA #$20 → ★PPU 地址合成
   字节 <$20：偏移量（ADC $14 续址）
   $14/$15 = 目标地址累加器（调用方 $04 组合）
   ↓
[写链-推进] bank15:$E6DF：$77:=$20（行标记）；$12/$13 += Y（跳过已读）；续读（≥$FE → RTS）
   ↓
[写链-预算] bank15:$E828：★VRAM 写预算管理（$20=已写计数；`$7E? $30 : $50` − $20 < 4 →
   JSR $E7D0 写 + 递归排空；$05/$06/$21 配额字段）
   ↓
[写链-寄存器] bank15:$E7D0/$E7DC/$E7ED：寄存器保存 → $1A/$1B 门控（PPUCTRL/PPUMASK 影子）
   → $2000/$2005/$2006/$2007 写入
```

**写点终谳**：文本记录的物理写点 = **`$E7DC` 族寄存器写**（经 `$E828` 预算门）；
**`$2006`/`$2007` 写值来源 = $14/$15 地址累加器**（由流字节合成，非 $8E/$8F 体系）——
双装载体系（t113）的文本侧通道**全链闭合** ✓。

## 2. 装配源（②）—— 部分收（如实）

- 流基址 = **`$2F/$30`**（bank00:$96CE）；`$2F/$30` 具**多用途复用**（HUD 序列器 t109 用作
  倒计时、此处作流指针——同址不同时序）。
- ROM 文本块 → 运行时流的**变形例程未定位**（t115 无命中延伸）：流指针可能直指 ROM 文本块
  （无需变形）或经 RAM 中转——**W50**（探针 $2F/$30 写流可定，见 §4）。

## 3. W46 顺带收（③）—— **$04 = VRAM 预算残差（B 级）**

`bank15:$E841: SBC #$03 / STA $04` —— **`$04` 由写预算例程写入**（`$05−$03` 残差）；
精灵 Y 公式 `ADC $04`（t106）= **复用该暂存**——自机 Y 微摆的真值轨迹 = **VRAM 预算状态** ✓
（W46 收口为『共享暂存语义』，精确调用序待 W47′）。

## 4. 重试 #6 参数终版（报 captain，登记归 spec-writer/移植归 porter）

1. **place_text_records 通道**：流（$2F/$30→$12/$13）→ 地址合成（$14 累加/ORA #$20）
   → **$E828 预算门**（$20 计数、<4 flush）→ 寄存器写（$1A/$1B 门控）；
2. **地址合成规则**：`(流字节 & $1F) + $14 | $20`（$20-$7F 数据字节）；<$20 = 偏移；
   ≥$80 = 控制（$FE 终止/继续）；
3. **预算模型**：$7E=0 → 预算 $50/$30 双档；每写递减 $20 计数——移植端需复刻预算节流
   （否则帧内写入量偏差 → L4 像素差）；
4. 自机 Y：`$04` = 预算残差共享暂存（W46 收口）；
5. W50 探针建议：`probe_mem 002f 0030` 一次采样定装配源。
