## 1. 弹型参数体系（已证实 A/B 级）—— M3 移植的核心数据结构

### 1.1 生成侧：六型自动连射循环（bank3:$A1FD-$A22B）

| 事实 | 证据 |
|---|---|
| 六弹型并行计数器 `$072E,X`（X=0..5） | `bank3:$A1FD` `LDA $072E,X`；到点 `bank3:$A20C` `INC $072E,X` |
| 周期表 `$074A,Y`（到点阈值） | `bank3:$A200` `CMP $074A,Y`；`>=` 则生成弹对象 |
| 弹参数 `$0766,X` → 对象脚本指针 | `bank3:$A228` `LDA $0766,X / STA $047E,Y` |
| 生成字段 | `bank3:$A20F-$A22B`：`$055E,Y`=Y（←$04FC 玩家Y）、`$04EE,Y`=X（←$04E0 玩家X）、`$063E,Y`=弹型码（=X）、`$040E,Y`=状态=1 |
| **无按键判断**（H-14 已定谳延续） | 循环体内仅计数器/周期比较——自动连射 |

### 1.2 参数来源：ROM 配置流（bank2:$9343-$938D）—— 等级耦合（H-02 补全）

```
$9354: $074A..$074F 清零（六型周期）
$9368: LDA $33        ; weapon_level
$936A: CMP #$04 / BCC ; 级<4 直接作索引
$936E: SBC #$04 / AND #$07 / ADC #$03   ; 级≥4 → 3+((级-4)&7)
$9374: TAY / LDX $9457,Y                ; $9457 = 级→配置偏移表
$937C: LDA $9463,X / BMI 结束           ; $9463 = 配置流
$9381: STA $074A,Y  (周期)  $9385+1: STA $0766,Y  (脚本参)  ; 逐对填 6 型
```

- **`$9457` = 12 级（0-11）→ 配置流内偏移表**：`00 03 0A 11 1A 25 30 3D 4A 57 64 71`
  （= 0,3,10,17,26,37,48,61,74,87,100,113）；级上限 $0C=12 与 t25 `INC $33` 回卷一致 ✓。
- **`$9463` = 配置流**：每级一段 `(周期, 脚本参)` 对，**$FF 负值终止**；对数随级增长
  （级0=1 对 → 级高=最多 6 对）——**weapon_level 的语义 = 同时激活的弹型数/频率**（H-02 收口补强）。
  级 0 样本：`05 0C FF`（1 型：周期 5、脚本参 $0C）；级 1：`03 0C | 02 0B | 02 0D | FF`（3 型）。
- **`$33`≥4 的索引变换**（`3+((级-4)&7)`）为实测事实；高配置段（偏移 $71 段）的可达性存疑 → 假设区 A1。

### 1.3 运动侧：对象脚本机（bank2:$87B3-$8810）—— 弹丸速度/方向/生命周期

| 对象字段（SoA，X=槽） | 语义 | 证据 |
|---|---|---|
| `$040E,X` | 动作计数器/寿命（逐帧 DEC） | `bank2:$87B3` `LDA $040E,X`、`$87B8` `DEC` |
| `$047E,X` | **动作流指针**（初始=弹参数 $0766） | `bank2:$87BD` `LDY $047E,X`、`$87E7` 回写 |
| `$05CE,X` | 当前运动指令码 | `bank2:$87D2` `STA $05CE,X`、`$87EA` `LDY` |
| `$04EE,X` | 对象 X 坐标 | `bank2:$87F3/$87FF` `ADC/STA $04EE,X` |
| `$055E,X` | 对象 Y 坐标 | 同构（$88CF,Y 速度路径） |

**ROM 运动表**（同一指令码 Y 索引）：

| 表 | 语义 | 实测字节样本（file 0x48CB 起） |
|---|---|---|
| `$88BB` | **X 速度分量 LUT** | `09 08 05 03 00 FD FB F8 F7 F8 FB FD 00 03 05 08`…（16 向循环模式，带符号） |
| `$88CF` | **Y 速度分量 LUT** | `F8 F8 08 08 00 03 06 08 09 08 06 03 00 FD FA F8…` |
| `$890B` | 动作流（每步=运动指令码；含跳转值） | `41 C1 C1 C1 81 81 81 81 01 01…`（file 0x48FB 区） |
| `$892F` | 动作时长表（0=跳转指令→`$890B` 取新指针） | `bank2:$87C0` `LDA $892F,Y / BNE` |

- 取指循环：时长耗尽 → 从 `$890B` 取下一运动码写 `$05CE,X`、指针++ → 按 `$88BB/$88CF` 分量加坐标；
  运动码最高位为方向标志（`bank2:$87F1` `BMI` 负向路径）。
- **弹型差异的本质 = 不同初始动作流指针（$0766 配置）+ 不同发射周期（$074A）**，共享同一套
  16 向速度 LUT 与脚本机 —— M3 移植可按「配置流 + 脚本机 + LUT」三件套实现。

## 2. 射击模式分派（bank3:$A1F5-A2B2）与 $34/$33 耦合

| `$34`（weapon_slot） | 行为 | 证据 |
|---|---|---|
| 0 | **六型自动连射**（§1.1 循环） | `bank3:$A1F5` `LDA $34 / BNE` 分支 |
| 1 | type3 齐射：填充 `$0402,Y` 槽（type=3） | `bank3:$A271-$A291`，`LDX #$03` |
| 2 | type4 齐射 | `bank3:$A275-$A28F`，`LDX #$04` |
| 3 | 退出（不发弹） | `bank3:$A244` `CMP #$03 / BEQ` |
| >3 | type6 齐射（循环填 `$36` 槽） | `bank3:$A24C-$A26F`，`LDX #$06` |
| A 边沿（独立） | 投放：`$0401` 门控 + 消耗 `$018F`（t22/t25 已证） | `bank3:$A2B4` |

- **$33（weapon_level）不改变弹型码、改变配置选择**（§1.2）：同型圈连收升级 → 更多/更快的并行弹型。
  —— H-02『升级机制』完整答案：升级=激活弹型数与周期变化，非换弹型码。

## 3. t28 遗留收尾

### 3.1 Q1 —— 已证实（A 级）：`$0190` 拾取处理器 + `$3B` 连收计数

```
bank2:$9698  CMP $0190        ; 拾取物类型 vs 当前
bank2:$969B  BNE $96A1        ; 异型 → $3B 清零
bank2:$969D  INC $3B          ; **同型连收计数 $3B+1**（t22 观测 $3B 恒 0 ✓ 无连收）
bank2:$96A5  STA $0190        ; **$0190 = 当前拾取物/弹种类型**
bank2:$96A8  LDA $018F / CMP #$20 / BCS …  ; **弹数上限 $20（32）**
```

- f2220 双写解释：拾『W』经本处理器写 `$0190=3`；同帧 `$34=3` 系编号圈处理器（bank2:$922B）
  或同帧双拾取——两者数值同为 3 源于 **W 在 F/B/T/W 序列的索引=3**（E-R08 序），非字段共用。
  剩余不确定性（同一拾取物触发两处理器？）→ 假设区 A2。
- **新事实**：`$3B` = 同型拾取连收计数（升级触发器候选）；弹数上限 32（与 H-11『20 上限』的
  表述差异 → 假设区 A3，商店文案单位待考）。

### 3.2 Q3 —— akey-role 干净重跑（防踩踏驱动）：**W8 彻底证伪 + $0401 语义升级**

- **外来位检查**：整场 2200 帧（实机段 f1260-2199）**方向位恒 0、A 位仅在计划窗**；
  4 处边界差异全部为统一 +1 帧注入延迟（f1520/1524、1600/1701）——幻影输入不复现 ✓
  （孤儿 run 干扰定性成立，ram-watch-s3.md §9.5 更正维持）。
- **`$0401` 干净时间线**：`0`（菜单）→ `124/110`（f203/f206，商店选择态=同址多用途佐证）→ `0`（f913）→
