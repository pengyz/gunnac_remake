## 0. F1 恒等式张力裁定（本审裁决，核心交付）

**裁定：D3 优先级原则采纳，但 0.26% pair 判优暂缓采信——张力主因=测量域污染，次因=未察细节（非两者取一 ✓）。**

1. **D3 真相锚是双元**："ROM 字节 + Mesen2 执行是最终真相"——恒等式（bank=124+code//64）恰好站在
   **ROM 字节一侧**：bank124/125 逐码 25/25 字母 + 10/10 数字 + 15/15 标点全表字形成形（t176 决定性验证）
   ——这是 ROM 级硬证据，非纯"推导产物"；
2. **0.26% 无裁决力（测量域污染）**：本审 t173 逐格证据——字体变体影响域仅 **14 格/171px oracle ink**，
   而两变体在该域**共同偏差 ≈2,000px**（预测 ink 2,112/2,620 vs oracle 171）；变体差（≈150px）仅共同误差
   的 ~7%，判别格 **38:37 近平**——污染域内的相对排序不能推翻硬证据；
3. **"bank125/126 同源性"假设排除**（本审逐字节）：`bank125+10 = 06 06 06 06 06 c6 7c 00`（J，8×16 双半重复）
   vs `bank126+10 = 00 04 04 ff 04 3f 00 3f`（非 J）——**不同源**，该假设关闭；
4. **裁定措辞**：恒等式**保真维持**（非"留变体"）；oracle 判优原则保留但 pair 判优**挂起**至低误差域复测；
5. **后续取证方向**：先修放置/可见性大头（t181 W69 CJK 象限放置线；当前 oracle 该域近乎空白而渲染大量落墨
   = 主误差源），共同误差显著下降后在低误差域复测 pair vs linear——届时差分才有裁决力。
