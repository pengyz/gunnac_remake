## 2. attr 语义定谳（②）—— **H-flip + palette + bit4 标志（A 级）**

251/253 全程 attr 分布：{$12(952)、$52(876)、$02(280)、$01(280)、$42(280)}：

| attr | 位解 |
|---|---|
| $02/$01 | palette 2/1 |
| $42 | **H 翻转（bit6）** + pal 2 |
| $12 | **bit4** + pal 2 |
| $52 | H 翻转 + bit4 + pal 2 |

→ **attr $52 = H 翻转 + bit4 标志 + pal2**（非 V 翻转——【若 t214/t216 称 V 翻转系误注，
按 $52 位解为准】）；**V 翻转位（bit7）全程 0**——『vflip 变体』在渲染变换层不存在于该族
（bitmap 穷举已含 vflip 亦无命中，见 §1）。
