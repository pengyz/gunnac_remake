## 1. F1 六型生成器零活动之谜 —— **定谳：B 键门控（非自动连射）**

**门控链（bank3:$A184-$A1C2，A 级反汇编）**：

```
$A184: LDA $32 / AND #$08 / BEQ $A1A9     ; $32 bit3 分支
$A193: LDA $18 / AND #$40 …               ; bit3 置位路径：B 键 → $3A=5 → JMP $A23D（槽模式分派）
$A1A9: LDA $18 / AND #$40 / BNE $A1B6     ; ★B 键按住（$18 bit6）→ 连发路径
$A1AF: LDA #$01 / STA $3A / JMP $A2B2     ; B 未按 → 直接收尾（不射击）
$A1B6: DEC $3A / BNE $A1B3                ; ★$3A = 自动重复倒数
$A1BA: LDA $39 / STA $3A                  ; 倒数归零 → 从 $39 重装
$A1BE: LDA $32 / AND #$04 / BEQ $A1F5     ; $32 bit2=0 → ★六型生成器
```

| 结论 | 级 |
|---|---|
| **主武器 = B 键按住连发**（$18 bit6）+ 自动重复计时器 $39/$3A（$39=重装值=8，t13 `LDA #$08/STA $39/$3A`） | A |
| `$18` bit6 = **B 键**（trace 实测 f1501 `press 1500 b` → $18=$42/$16=$40） | A |
| `$32` bit2 = 六型生成器门（置位→跳过）；bit3 = B 键行为二分（A23D 槽模式 vs A1F5 六型） | A |
| 计数器复位：`bank2:$91B3` = 清零 $072E-$0733 全六计数（调用点：拾取深路径 $926E、$91C8 族） | A |
| 计数 INC：`bank3:$A20C`（每次成功生成 +1）；语义=已发数/周期进度（$074A,Y=周期阈值，到顶停发待复位） | A |

**★ t29 H-14/N-0035『主武器=无条件自动连射』定性撤回**：生成循环体确无按键判断（该观察成立），
但**调用方 $A1A9 存在 B 键按住门控** —— 无 B 长按的 gameplay-stage1 自然 0 命中（F1 谜底）。
t25『B=弹种切换（$A193/A1A9 AND #$40）』同步更正：该两处 = **主武器连发触发**，非弹种切换。
R-shot-gen-1..3 规则措辞需按此更正（登记归 spec-writer）。

**动态复核（`oracle/scenarios/fire-hold.txt`，B 长按 1000 帧）**：
`$072E` 计数随生成递增（1301→1、1308→2…，每 7 帧一发）；槽位填充可观测（§2）——
**R-shot-gen 写链可观测达标** ✓（任务①达标判据）。

## 2. F2b 槽位 state 字段语义 —— **定谳：逐帧寿命倒数**（t48 维持，t50 反证系伪影）

`fire-hold` 实测槽位时间线（20 槽 state 地址）：

```
f1301: slot0=255   f1302: 254   f1303: 253 … f1307: 249   → 每帧 −1
f1308: slot0=248, slot1=255（新弹）→ 双弹并行递减
```

| 裁定 | 内容 |
|---|---|
| **state = 寿命倒数计数器**（初值经动作流装载（$892F 时长表），观测 $FF 起逐帧递减至 0 释放） | A |
| t50『20 帧不递减/静态非寿命』**反证解**：gameplay-stage1 无 B 长按 → **零弹生成**，该址非零字节 = **$1C 网格交错的阶段对象字段值**（非弹 state） | A |
| 机器 `bank2:$87B3` DEC $040E,X = 倒数本体；槽迭代 `bank3:$AB84-$AB99`：X+=**$7E** 后 +**$1C**×3（组起点 $80/$9C/$B8/$D4 族，与 t48 分配器几何吻合） | A |

**churn 统计口径更正**：t48 的 gameplay-stage1「最大并发 9」系**网格污染值**（口径错）；
正确口径（fire-hold 真实弹数分布）：并发 0-9（众数 2-6），峰值 9、容量 20 未饱和 ✓
—— t48 几何/分配器结论（N-0068/0069）**维持**，仅 churn 证据字段更正。

**交错残余（W7）**：20 槽 state 地址（$048E-$0492/$04AA-$04AE/$04C6-$04CA/$04E2-$04E6）与
$1C 网格 n=5..8 字段阵列（$048C/$04A8/$04C4/$04E0 + 槽 X=2..6）**同址** —— 两系统对同字节的
所有权/时分复用机制未证（fire-hold 中弹 state 主导该址；无弹时网格值驻留）→ 假设 W7。
