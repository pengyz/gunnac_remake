## 0. 判定摘要

1. **「$0160 非零写 4000+/帧」是伪象**（A）：那 149K 条是**读事件**（`bank15:EED1 LDA $160`
   忙等自旋的轮询读），不是写。本 trace 中 $0160 的**写事件只有 1 条**（boot 块清零）。
2. **probe 有写点盲区**（A）：非变址（绝对/零页）STA/STX 存储**全部不触发回调**——$0160 的
   12 个 ROM 写点无一可见。变址存储/读/RMW 可见。⇒ "写事件流重建 flag"的回放前提失效。
3. **$0160 = 单槽挂起位域 + NMI 单点消费**（A 结构 / B 语义）：不是脉冲队列；一帧至多一次
   NMI 消费（F0DC 轮询 1 次/帧）。「一次 v=1 置位 = 一次行上传请求」读侧 1:1 成立（B+）；
   「同帧多次 v=1 = 多批」不成立。
4. 渲染端：**帧末单快照语义"已证正确"不成立（改判未闭合）**；建议按「单 pending 槽 +
   NMI 消费点」驱动上传（§5）。

## 1. probe 语义定谳（A 级，先校准再统计）

`tools/scenario_capture.lua:145-178` 注册 `emu.addMemoryCallback(fn,"write",lo,hi)`，但日志
**读写混合**；`pc`=`emu.getState()["cpu.pc"]`，实测=**访存指令的后取指 PC（下一条指令地址）**。
校准锚点（seed 逐条对上）：

| 事件 pc | 真实访存指令（seed） | 类型 | 校准判据 |
|---|---|---|---|
| `E041` | `bank15:E03E 9D 00 01 STA $100,X` | 写 | a=$0100+x，x=111→96 递减，v=0（boot 清零块扫） |
| `EED4` | `bank15:EED1 AD 60 01 LDA $160` | **读** | 自旋体 `EED4 D0 FB BNE loc_EED1`（seed L89184-85） |
| `F0DF` | `bank15:F0DC AD 60 01 LDA $160` | **读** | NMI 轮询体，1 次/帧（2,400 条/2,403 帧） |
| `F1FC` | `bank15:F1F9 BD 00 01 LDA $100,X` | 读 | a=$0130-$015F，x 递减 |
| `E8E3` | `bank15:E8E0 9D 03 01 STA $103,X` | 写 | 变址写 $0130+X，v=字符码 |
| `EFA5` | `bank15:EFA2 8D 14 40 STA $4014` | DMA 读 | a=$0200-$02FF 顺序 256 条/帧（OAM DMA 读页） |
| `EEDC` | `bank15:EED9 99 61 01 STA $161,Y` | 写 | Y=$FF 回绕命中 $0160（1 条） |
| `88A3`* | `bank00:88A0 0D 60 01 ORA $160` | RMW | 读相位旧值（*他 trace，§3） |

STA $160`)、`EC45`(=`EC42 STA $160`)、`88A6`(=`88A3 STA $160`)、`F10C`(=`F109 STA $2007`) 全部
不存在，而其上游指令事件齐备（如 F109 读 $161 共 280 条 ⇒ 该路执行 280 次，`STA $2007` 0 条）。
变址存储（`9D/99` 系）全部可见；**RMW 只出 1 条/次、值=修改前旧值**（`88A0 ORA $160` 事件 v=0
→ 随后 F0DF 读到 1，三 trace 计数严格 1:1，§3）。

## 2. $0160 统计表（gameplay-stage1）

| pc | 归属指令 | 类 | v | 条数 |
|---|---|---|---|---|
| `EED4` | `EED1 LDA $160`（EECC 握手自旋） | 读 | 3 | 149,309 |
| `EED4` | 同上（自旋退出读） | 读 | 0 | 40 |
| `F0DF` | `F0DC LDA $160`（NMI 轮询） | 读 | 0 | 2,330 |
| `F0DF` | 同上（NMI 见挂起） | 读 | 3 | 70 |
| `E041` | `E03E STA $100,X`（boot 块清零） | **写** | 0 | 1 |

- **v 值分布：0=2,371；3=149,379；1=0；2=0；其它=0**（$0160 共 151,750 条）。
- **v=1：本 trace 0 条**（读写皆无）——"BBBD 族"不成立于本 trace（跨 trace 见 §3）。
- **v=3 pc 分布：`EED4`（自旋读）149,309 + `F0DF`（NMI 读）70**；v=3 的**写**点不可见
  （EECE/EEE1 abs 存储盲区）。「EED4=脉冲写点族」标签**错误**。
- 帧分布：buf 区（$0130-$015F）事件 550 帧（**变址写**事件 389 帧，余为 NMI/F1F9 读）；
  $0160 事件 2,403 帧；非零观测 107 帧；v=0 观测 2,371 条 ≈ 1 条/帧。
- 帧内 $0160 计数 Top：10/155/160/165/170/175/180/929/26/1223/1218/16（4,000-4,200 条/帧）
  ——**全部是 EED4 自旋读**（v-dist {3:~4000} 或 {0:1, 3:~4000}）。

### EED4 自旋会话（A 级结构）

`bank15:EECC A9 03 / EECE 8D 60 01 STA $160 / EED1: AD 60 01 LDA $160 / EED4 D0 FB BNE / EED6 RTS`
= **置类型 3 → 自旋等 NMI 清零** 的阻塞式握手。启发式切分 **64 会话**，每会话 3,000-4,200 次
轮询读、跨 1-2+ 帧、以 1 次 v=0 读退出（共 40 次退出观测）；成簇（帧 248-259、908-940、
1179-1224）。**每会话=一次挂起请求，阻塞至 NMI 消费** ⇒ 生产者不可能在同一槽上排队多批。

### NMI 消费侧（A 级）

`F0DC` 轮询 2,400 条（≈1/帧）：v=0 2,330 / v=3 70。70 次见 3 中 **40 次落在自旋会话内、
30 次在会话外** ⇒ 存在第二条 type-3 生产路（非自旋；seed 候选 `bank15:EEDF A9 03/EEE1
STA $160/RTS` 脉冲式，写不可见，B 级）。

## 3. v=1 与 BBBD 族（跨 trace 对账）

| trace | `F0DF` 读到 1（NMI 观测） | `BBBD` 读到 1 | `88A3` 事件（RMW 旧值 0） |
|---|---|---|---|
| stg03-timeline | 385 | — | 385 |
| stg08-timeline | 410 | — | 410 |
| gs5-anchor-render | 197 | — | 197 |
| tas-stg08b2-dense | 1,030（1,030 帧，≤1/帧） | 40（39 帧，≤2/帧） | — |

- `BBBD` = **`bank3:BBBA AD 60 01 LDA $160` 的读**（seed 字节流 `…BBBA AD 60 01 09 01 8D 60 01 60`
  = `LDA $160 / ORA #1 / STA $160 / RTS`）；setter `BBBF STA $160` 不可见（盲区）。
- `88A3` = `bank00:88A0 0D 60 01 ORA $160`（RMW 读相位旧值 0）；三 trace 与 F0DF 读到 1 的计数
  **严格相等**（385=385、410=410、197=197）⇒ **一次置位 = 一次 NMI 消费**（读侧 1:1）。
- tas-stg08b2 的 v=1 结构：`F0DF` 读到 1 呈**连续帧 run**（run 长：13×28、62×3、34×3、69×2、
  7/14/27/56/6/18/28/11 若干 + 35 孤立帧），逐帧上下文=`F0DF=1 → 帧内 BBBD=0 → BBBD=1 →
  下帧 F0DF=1`（帧 22801-22807）⇒ **每帧一次「置位→NMI 消费」循环**：非长电平、非同帧多批。

## 4. 帧内序列样例（a/v 顺序，gameplay-stage1）

**帧 155**（自旋会话中）：`F0DF a=0160 v=0`（NMI 见空）→ `EED4 a=0160 v=3 ×4019`（自旋：
EECC 已置 3，写不可见）→ 帧 156 续 16 条 v=3 → NMI（EFA5 DMA 段）后自旋见 0 退出。

**帧 181**（握手尾 + 缓冲填充）：
```
EED4 a=0160 v=3 ×17        ; 自旋尾（承接帧 180 的 EECC 调用）
F0DF a=0160 v=3            ; NMI 轮询见挂起 3 → 本 NMI 消费（上传+清零，写不可见）
EED4 a=0160 v=0            ; 自旋退出读
E8E3 a=0130..014F v=122,123,48,14,34,9,52,53,54,55,55,48,56,57,58,59,60,61,62,63,0,0,… ; 变址写填充行缓冲（字符码）
```

**帧 182**（缓冲被读 + 再填充）：
```
F1FC a=0130..014F v=255 ×32 ; F1F9 LDA $100,X 读行缓冲（另一消费路）
F0DF a=0160 v=0            ; NMI 轮询见空
E8E3 a=0130..014F v=255 ×32 ; 再次填充
```

**帧 1693**（NMI 上传路）：
```
F09D..F0C7 a=0130..014F v=0 ×32（x=0/8/16/24 四组×8）
    ; bank15:F09A BD 30 01 … F0C4 BD 37 01 LDA $130..137,X —— NMI 上传读取体
F0DF a=0160 v=0             ; NMI 轮询
```

时序关系（B 级）：本 trace **无 v=1**，「同帧 buf 写→v=1」不可直证；观测到的成对关系是
「变址填充（E8E0 族；帧 1205/1206 各 488 条写）」与「type-3 握手（约 64 次，阻塞）」分属
不同帧段；填充→置位→NMI 消费的完整链因 setter 写不可见无法逐拍闭合（G3）。

   多置位合并）。
