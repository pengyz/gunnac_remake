## 1. 进给节律（spawn 节律，A 级）

- 记录四参 `(组员type, 组员数, 间隔帧, 参数)` 的 arg2 = **组员出敌帧间隔**（stg02-timeline §3
  双关签名 10/10 定谳）；实测值域 {10,15,20,24,25,30,40,50,60,80,90,100,120,180,200}f。
- B1 §3 的「10f/15f 摆动进给」= 进给节律 10f/15f + 出敌 x 位置摆动（§2）；
  **进给与运动分离**：$534 只管投放节奏，对象落地后的逐帧运动由行为机驱动。

## 2. 轨迹族实测（A 级：iram $04E0+槽/$04FC+槽 逐帧序列）

### 2.1 族①正弦摆动 + 恒速下沉（$2B，关1 f1479-1595）

x(t) 实测（4f 采样）：190→187→182→175→165→154→141→126→111→98→87→79→72→67→64→64→65→68→73→81→90→101→114→130→144→157→168→177→178
dx 序列：−3,−5,−7,−10,−11,−13,−15,−15,−13,−11,−8,−7,−5,−3,0,+1,+3,+5,+8,+9,+11,+13,+16,+14,+13,+11,+9,+1
——**速度分量正弦进给**（幅值 ≈ ±4px/f），y 恒速 +2.5px/4f 下沉。

拟合（B 级）：`x(t) ≈ 127 + 63·sin(2π(t−1543)/104f)`（左极 f1543 x=64、右极 f1595 x≈178，
半周期 52f ⇒ **T≈104f**）；残差 ≤3px（视界内）。

### 2.2 族②线性下沉（$51，关2 f4572-4664）

dy=+10px/4f 恒定 23 帧 → 直落 y=238 出屏；x 恒 127（中线）。零摆动。

### 2.3 族③减速下沉 → 加速横移（$56，关2 f3806-3978）

下沉 dy：+9,+9,…→+1 递减（ease-out，≈40f 到 y=186 底部驻留）→ 横移 dx：+2→+18 递增（ease-in）。

### 2.4 族④加速下沉（$55，关2 f4707-4779）

dy：+5→+18 递增（ease-in），x 恒 195。

> 说明：f3810/f4576/f4707 等首采样大跳 = 出敌首帧的定位写（「0,0→后动」同源现象，
> B1 §2.3 注）；槽复用旧值不清零（B1 口径）。

### 2.5 型值迁移实测（Wt-5 升级素材，A 级）

关1 slot09：f1479-1591 为 **$2B**（摆动族）→ f1595-1623 变 **$12**（驻留）→ f1627 起变 **$4E**
（直线下降 x=16 恒定）——**同槽三段型值迁移**，行为相位随型值切换；B1 Wt-5

## 3. 速度表接线（A 级静态 + L2 锚）

### 3.1 链 A：16 向速度分量 LUT（shot 运动机）

`$88BB` = X 分量 LUT（`09 08 05 03 00 FD FB F8 F7 F8 FB FD 00 03 05 08`，16 向循环带符号）；
`$88CF` = Y 分量 LUT（`F8 F8 08 08 00 03 06 08 09 08 06 03 00 FD FA F8…`）。
消费机 = shot 运动机 `bank2:87DA-881B`（L2 已对拍 `shot_lut_accumulate`，B1 §1.5 + shot-behavior §3）；
动作流 `$890B` 取运动码 → `$05CE,X`，时长 `$892F,Y`（0=跳转取新指针）；逐帧
`$04EE,X+=$88BB,Y / $055E,X+=$88CF,Y`（[shot-behavior.md](shot-behavior.md) §2）。

### 3.2 链 B：Wt-6 三角波表（弹速摆动接线点）

`bank05:8C8D-8CA9`（逐指令）：

```
8C8D  FE DC 05  INC $5DC,X        ; 逐槽计数器++
8C90  BD DC 05  LDA $5DC,X
8C93  29 07     AND #$07          ; mod-8 定宽
8C95  A8        TAY
8C96  B9 5F AC  LDA $AC5F,Y  → STA $684,X   ; 三角波 D3 D7 DB DF E3 DF DB D7（B1 §3 真值）
8C9C  A5 2B     LDA $2B
8C9E  29 01     AND #$01
8CA0  59 67 AC  EOR $AC67,Y  → STA $534,X   ; 相位随 $2B bit0 翻转
8CA6  B9 6F AC  LDA $AC6F,Y  → STA $518,X
```

- **摆动动力学的引擎核心**：mod-8 计数器 × 对称三角波表 = 速度分量正弦/三角进给
  （与 §2.1 的 dx 正弦序列同构；`$AC5F` 表首 8B 真值=对称三角波，B1 §3 复核 #76 F2）。
- **字段复用现身**：`$518+槽/$534+槽` 被运动机重写——stg02 §3.4「组员槽字段残值非四参链写点」
  的写主即此（四参链写入后，运动相位接管同字段）。**移植注意**：字段生命周期分两段
  （投放控制期=四参；运动期=速度分量），不可混用。
- 第二消费点：`bank07:AAD9-AADC`（`LDY $5DC,X / LDA $AC5F,Y`——无 AND#7 裸索引，形态待证）。

## 6. 复现命令

```bash
# 轨迹序列（§2）：iram $04E0+槽= x / $04FC+槽= y 逐帧
python3 - <<'PY'
import json
def traj(path, lo, hi, slot):
    out=[]
    for line in open(path):
        try: d=json.loads(line)
        except Exception: continue
        f=d['f']
        if not lo<=f<=hi: continue
        ir=bytes.fromhex(d['w']['iram'])
        if ir[0x100+slot]: out.append((f,ir[0x100+slot],ir[0x1E0+slot],ir[0x1FC+slot]))
    return out
for f,t,x,y in traj('analysis/traces/gameplay-stage1.frames.jsonl',1479,1720,9)[::4]:
    print(f, f"${t:02X}", x, y)
PY
```
