## 6. W43 追加（captain 范围并入）：HUD 槽分配例程 —— **直写 + 序列器定谳（A/B 级）**

**HUD 装配 = 绝对地址直写（非 $52 发射器路径）**：

```
bank00:$8F24: STA $0200（Y 变量）→ $0203:=$4C（X）→ $0202:=0（attr）→ $0201:=$BF（固定字模 tile）
bank00:$8F36: JSR $8FEE  → ★HUD/intro 序列器
```

**序列器 `bank00:$8FEE`**：`$31` 计数驱动（INC，阈值 $1D/$32/$64 = 29/50/100）→
tile 切换（$BF/$4E/$4F）、调色板挂起（`STA $160`）、数据指针（$924E 族）——**开场/HUD 动画时序器**。

| 裁定 | 级 |
|---|---|
| HUD 槽 0 = **直写分配**（$8F24，tile=$BF 字模），与发射器 $52 体系并行 | A |
| HUD/intro 动画 = `$31` 计数序列器（阈值 29/50/100 三段） | A |
| f1500 快照 HUD 簇（槽 4-8/61-63）= 其他 HUD 写者（b0:$9C28 族）——逐簇归属待 W48 | B |

→ t103『$00-$0C HUD 预留区候选』修正：**槽 0 为序列器专用**，其余 HUD 槽分布非连续
（4-8/61-63），分配 = 各写者直写 + 发射器 $52 双体系并行（N-0126）。
