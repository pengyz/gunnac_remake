## R-3 · fade 参数源（2026-10-16 点名，收——改写器值源=调色板命令流）

**机制链（A 级，bank00:8530-8618 全链）**：

```
调色板命令流（$14:$15 指针，($14),Y 消费）
  → 流解释器（8530-857F）：
      数据字节+计数 → JSR $8619（改写器入口：$10:=索引/参数装）
```

**R-3 答案（A 级）**：位域改写器的**值源表=命令流字节本身**（无独立 fade 值表！）；
**初始相位=流首命令**。S5-2 的 fade 序列（77→53→24→…→0）=**命令流数据字节的逐帧回放**
（每帧解释一段流）——「表候选排除」旧谜底 ✓（序列生成于流，非静态表）。
