## 2. 波次流签名对账（对照模板）

`python3 tools/wave_stream_decode.py wave 6`：

```
== STG-06 op5 波次记录流（bank10；§1.4 字段格式 23B/记录）==

-- 流 $A5D9（脚本 thr=$0412）--
  @A5D9 C9=$E2(bit1→速度快照) CA=$00(—)
        速度字节=$07 $7F=$02 写表1=$0000 写表2=$0000
        清单=$A5EE count=1 types=[$AD] $D2=$00 $D1=$0A/$14
        ED3B=$00/$0F/$00 DB4C=$12 ED6C=$0000/$0000 next=$AD01
        （C9 bit2=0：不跳转，链止）

-- 流 $A5F0（脚本 thr=$0420）--
  @A5F0 C9=$FB(bit0→far-call bank11:$8012 bit1→速度快照) CA=$01(bit0→$26|关末门)
        速度字节=$07 $7F=$02 写表1=$0000 写表2=$0000
        清单=$A605 count=1 types=[$AF] $D2=$00 $D1=$0A/$1E
        ED3B=$0C/$0F/$A5 DB4C=$14 ED6C=$0000/$0000 next=$AF01
        （C9 bit2=0：不跳转，链止）
```

**差异注**：流1/流2 模板不变量全守；差异——
① 流1 C9=**$E2**（关4 同变体，bit4=0；模板 $F2——C9 位义横切项 S3-3 又一数据点）；
② 流1 CA=$00（回模板基值；关3/5 为 $70——CA 流1 位义三形态 $00/$70/$00 交替）；
③ 写表**全零**（流1/流2，与关4 同）；
④ 清单型值 $AD/$AF（不命名）；流2 CA=$01（关4 同最小臂门集）；
⑤ 波次对 thr $0412/$0420 = **间隔 14 tick（八关最小波次对间隔）**；
⑥ LUT=$A5D6→流1 $A5D9（+3B，Wt-3：+9/+4/+11/+4/+8/+3）。
