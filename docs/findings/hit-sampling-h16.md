## 0. 网格寻址更正（前置）

t32/t40 系列分析中 `base+n×$1C` 的槽寻址**有误**（对 SoA 的误读）——正确为
**字段基址 + 槽号 n（stride 1，28 槽）**：`$04E0+n`=X 坐标、`$04FC+n`=Y、`$0400+n`=类型、
`$05DC+n`=命中/清除倒数、`$0684+n`=退场标记字段…（字段基址间距 $1C = 28 = 槽数）。
本报告全部按正确寻址重算；t40/t52 的 spawn-event 计数曾用错误寻址（其 respawn/弹药结论不受影响，
系基于标注 watch）。

## 1. 命中清除链定谳（A 级 trace 实证）

**命中样本 f1404（fire-hold）slot#8 字段列差分（f1403→f1405）**：

```
$0408 (类型):      18 → 0     ★槽释放
$0424 (子像素):   131 → 0
$0478:            224 → 0
$0494:            208 → 0
$05C8 (速度族):   176 → 16
$05E4 ($05DC+8):   4 → 0     ★命中/清除倒数归零
```

| 裁定 | 内容 | 级 |
|---|---|---|
| **`$05DC+n` = 命中/清除倒数字段**（t32 HP 候选簇成员）：接触帧归零 → 类型字段清 0 = **槽释放** | A |
| 归零即释放（同一观测窗内类型 18→0）——『命中触发清除』链显形（t64 W14 部分收口） | A |
| `$05DC` 语义二读（HP 计数 vs 死亡倒数）：respawn-window 中 55 次自然递减（无弹环境）倾向**倒数/计时读**；HP 读（初值 4）不排除 → 维持双读备选（W18） | B |

**火-hold 命中富集统计**：槽释放 91 + $05DC 递减 40；其中 **10 例弹近距（|dx|≤12,|dy|≤16）接触** = 命中样本集（§3）。
