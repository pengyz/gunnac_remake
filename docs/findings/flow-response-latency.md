## 3. 输入锁窗口（引证 A 级，AR54/复核 #54）

| 版本 | 标题段锁边界 | 实测 |
|---|---|---|

- 我的 trace 与 AR54 口径相容：press 420a/600start 均锁存成功但无响应（$18 有、场景不变）——
  **锁作用在响应层非锁存层**（B 级推定：门控在场景状态机消费侧）。

## 4. 段判别字段（port 接线用，A 级）
