## 7. 【2026-10-16 补·S5-2 ①】转场尾 33f 帧内分布——三字段定名（port 双窗解剖回流）

> port 双窗实测（stg03 f5571-5604 / stg04 f7371-7404 逐字段同构）三段结构 + 本节代码面定名：

| 字段 | 定名 | 证据（A 级） | 观测解读 |
|---|---|---|---|
| **$2C** | **rng_state**（LFSR 状态字节） | bank15:EC12（`$2C:=$2C+$2D+1 ^ $2B`）/EC1F 消费——S4b-9 $EC12 定谳同源 | 段1「1→18→52→120 突发」=**RNG 调用痕迹非 fade 段**（port 疑似注收敛 ✓） |
| **$23** | **nmi_pending_frames**（NMI 帧待处理计数） | bank15:EF91 `INC $23`（NMI 置）/ E239-E23F 主循环**自旋消费清零**（`LDA $23/BEQ` 自旋→`STA $23`） | 「首步 1,2,3,4,5→0,0,0,1」=主循环负载相位——**转场期每 ~4f 才消费一轮 = $04 4f 步进的机制源**（33f 分布核心） |
| **$04** | **fade_level**（暗度步进值） | 写者未钉死（61 写点多为 zp 通用暂存；E34E/E3C1 实测均为暂存用非 fade）——**候选=转场调色板 routine**（消费侧反查挂 S5-2 ①续） | 段2 77→53→24→23→20→17→4→0 每 4f 一跳=主循环 cadence 驱动 |

**三段结构重读**（port 实测 + 代码面定名合流）：
段1（4f）= RNG churn（转场预备期调用痕迹）；段2（~25f）= **fade_level 步进**（4f/步，
~6-7 步；步进间隔=主循环 cadence（NMI 计数积压消费））；段3（完成帧）= 状态整批重置
（$27:=$00 防重入释放 + $18 双端锁释 + 调度机 $3E-$43/$4F-$5F/$84/$86/$87 族）。

**引擎原语建议**（port ChainCycle 33f 常数→分布化）：fade_level 按表/公式步进 7 档
（77,53,24,23,20,17,4,0 数值源未钉——表/公式二候选）× **4f loop cadence** + 完成帧重置批；
段1 RNG 痕迹不入原语（非确定性面——RNG 为 GameRng 移植域）。

**边界（S5-2 ①续/②）**：$04 写者钉死（调色板 routine 消费侧反查）；77→0 数值源（表 vs 公式）；
$18 输入锁门控代码（响应层锁的精确机制=②）。

## 8. 【2026-10-16 补·S5-2 ①续/②半件】数值源二候选裁剪 + $18 门控两层模型

**① 数值源**：77→53→24→23→20→17→4→0（dec/hex 双释义）**全 ROM 三元组子串扫描均无命中**
⇒ **表候选排除**，结论收窄为**公式/逐色变换生成**（B 级）；$04 写者=转场调色板 routine 仍未钉
（已扫排除：shop init $9BC3 段 / 出店致谢渲染 $9C8B-$9CC6 段）——S5-2 ①续b 挂账。

**② $18 门控两层模型**（消费面 A 级；17 读点中菜单 UI 域 2 站点定谳）：
- **层 1（处理器内按下保持门）**：bank00:92AA `LDA $18/AND #$10/BNE $92A7`——**按住 START 自旋**
  （每轮回 $E59D 帧同步，释放才续行）；bank00:9400 `LDA $18/AND #$10/BNE RTS/JMP $931A`——
  **按住早退**（RTS=本次派发作废，释放在下一派发周期生效）。
- **层 2（相位机不派发）**：(450,550] 时间锁 = 标题揭示相位机在揭示完成前**不派发菜单输入处理器**
  （handler 根本不到达）——与层 1 叠加成「锁在响应层非锁存层」观测（§3）。
- 附注：bank03:A06E 系**自机移动输入**（$18&$0C→$588/$048C/$04FC 运动族，S4b-2x ① 同源）——
  非菜单锁；bank00:9C6B `$18&$33==$22` = 组合键判定（转场流内）。

**S5-2 ②余量**：(450,550] 相位边界帧的计时源（揭示脚本长度源）未钉——层 2 的精确相位表挂账。
