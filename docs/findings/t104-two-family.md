# t104 两族残余取证（t106）— BG 行放置链 + 精灵 Y/CHR/相位定界

> ①族 a：BG 行放置语义（nametable 基址上下文）；②族 b：**Y 锚点表 = 系统性偏差根因**、
> CHR 基址映射、OAM=f−1 相位；③重试参数建议（§4）。

## 1. 族 a：BG 行放置链（A/B 级）

**放置语义（t97/t100 链 + 本任务上下文定界）**：

```
$8D 行索引 → $EBF4 LUT（$2000+$40n）→ $8E/$8F → NMI（+$0F 偏移、4×8B、组间 +$20）
```

- **放置地址 = nametable 行基址 + $0F**（行内偏移 15）；每 NMI 32B（半行）→ 同行二次 +$20 步进补全。
- **上下文 nametable 基址**：菜单/HUD 族 = **$2000 系**（LUT [0-14]）；关卡内容批（f1204-1207）= **$2Bxx/$2Axx 系**（t97 实测地址流）→ **放置语义根因 = nametable 基址上下文切换**（N-0123）。
- HUD 内容行归位 = $2000 系行（LUT 前段）；关卡背景 = $28xx-$2Bxx 系（第二屏）。
- 行缓冲实值非零段（t102 遗留）= **半行 32B 快照**（$0F-$2E 段）——非零段即该半行内容 ✓。

## 2. 族 b：精灵精度三件

### 2.1 Y 锚点表 —— **系统性偏差根因（A 级）**

| 实体 | Y 发射值 | 证据 |
|---|---|---|
| **自机** | **`player_y − $30`**（+`$04` 微调；< $30 不发射） | bank3:$A15D-$A167 |
| **弹** | `shot_y − $08` | bank2:$881B-$881E |
| **敌** | `enemy_y − $08`（y-subpix/坐标双路） | bank3:$A988-$A99E |

→ **根因**：自机锚点 **−$30**（48px）为离群值——若移植端按统一 −8 处理，**自机精灵错位 40px**
⇒『加精灵反而劣化 96.5%<97.4%』**系统性偏差定界成立**（N-0121）。

### 2.2 CHR 基址（B 级 + 残余）

- 精灵图案表选择 = **PPUCTRL `$1A` bit3**（0=$0000 / 1=$1000）——t103 影子机制。
- tile#→CHR 偏移 = **pattern table 基址 + tile#×16**（8×8）；MMC3 CHR bank 映射（R0-R7）
  另行切换；**字模 124-127 bank**（t2）为中文字模——tile 号域与 bank 映射的逐 tile 对照
  待 W45（运行时 CHR bank trace）。
- ORA #$10 站点扫描多遇 data-island 邻接（教训族）——静态直读不可靠，登记替代法。

### 2.3 OAM=f−1 相位（A 级硬件事实）

- **DMA 期 = NMI（vblank 期）**（bank15:$EFA0）→ 本帧 NMI 装载的 OAM = **下一渲染帧显示**
  = **OAM=f−1 相位**（标准 NES 行为）。
- **偏差定界**：移植端若按 f 相位渲染（当帧 OAM 当帧显示）→ 精灵整体 **+1 帧偏移**——
  与 Y 锚点偏差叠加 = 96.5% 劣化来源（N-0122）。
