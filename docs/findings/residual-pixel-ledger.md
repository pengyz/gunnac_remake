## 2. 写值层差 / charmap 参与（②）—— **流=TILE 码直存（B 级）+ 层差定界**

  （无 RAM 中转变形——装配源 = ROM 直读 ✓）。
- **ROM 流内容**（bank8 `$ABFD`）：`00 4A 4A 4A 53 00 00 48 00 00 48 …` = **tile 码直存**
  （$48/$4A/$53 字模 tile 号，00 间隔）。
- **层差定界**：t118『观测缓冲 tile ≠ 流字节』——流字节本身已是 tile 码（bank8 候选）⇒
  **charmap（$9190/$9830）不在本写链内参与**（其转换发生在更上游/其他块族）；
  层差来源候选 = **bank 选择差异**（$ABFD 的 bank 归属由 R7 决定——bank8 vs bank9/10 内容迥异
  ⇒ **bank 错配即层差**，重试 #7 参数 #2）。
