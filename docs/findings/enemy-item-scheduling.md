| 面 | 结论 | 级 |
|---|---|---|
| 记录语义 | `[delay@0][项…][ctrl]`：**项序列在同一 tick 内原子顺序消费**——一条记录 = 一次批量投放 | A |
| 项语法 | 项 = `(type≥$10, param)` pair 直投 **或** ctrl 项（1/2/11/12 组长流、10 流内定型、13/14 寄存器写）；ctrl0=记录尾、ctrl3..9=流跳转（唯二出口） | A |

| set10 | 槽分配 `$C2C6` → `$400/$470` ← 流 2B + **`$48C:=(\$3E),0` 码流取参 + `INC \$3E/\$3F`**（每次消费 1 码流字节）→ 回项环 | A |
| ctrl1/2/11/12 | 组长投放 + 四参写（→组员流**跨 tick 滴灌**，stg02 §3）→ **回项环**（可与后续项同记录） | A |
| 双分配器 | pair 项=`$C304`、ctrl1/2/10=`$C2C6`（两变体，B 级注） | A |

## 1. 项消费环（A 级，bank00:86CE-870D 逐指令）

```
86CE  LDY #1              ; 跳过 delay@0
86D0  LDA ($14),Y          ; 项首字节
86D2  CMP #$10
86D4  BCC 86FC             ; < $10 ⇒ ctrl 分派
      ---- pair 项（type≥$10）----
86D6  STA $13              ; type
86D8  INY / 86D9 STY $12   ; 保存参数位置
86DB  JSR $C304            ; 槽分配器（变体 A）
86E1  BCS 86F9             ; 无空槽 → 跳过本项
86E3  TAX                  ; X=槽
86E6  STA $400,X           ; $400+槽 := type
86E9  LDA ($14),Y
86EB  STA $470,X           ; $470+槽 := param
86EE  LDA #8 / 86F0 JSR $EEE5   ; 副效果（A=8；效果未名 S4b-6）
86F3  INC $4B / BNE / DEC $4B   ; 饱和计数（$FF 不回绕 0）
86F9  INY / 86FA BNE 86D0  ; 下一项（项环）
      ---- ctrl 分派 ----
86FC  INY / 86FD ASL A
86FE  BEQ 86CD             ; ctrl0 ⇒ 记录结束（RTS）
8702  TAY / JMP ($870E,Y)  ; ctrl 跳表（1..14，B1 §1.3 同表）
```

**出口唯二**：ctrl0（记录尾）或 ctrl3..9（流跳转，`$88` 型新基址 + Y=0 + RTS，8795-87A3）；
**其余 handler 全部 `JMP loc_86D0` 回项环**（ctrl1 8770 / set10 87CA）——故记录可**混排**任意项序列。

## 2. set10 流内定型（A 级，bank00:87A4-87CA）

```
87A4  JSR $C2C6            ; 槽分配器（变体 B）87A7 BCS 87C1 失败跳
87AB  LDY $12 / LDA ($14),Y → $400,X    ; type := 流字节
87B2  INY / LDA ($14),Y → $470,X        ; param := 流字节
87BA  LDY #0 / LDA ($3E),Y → $48C,X     ; 附加参数 := 码流当前字节
87C1  LDY $12 / INY
87C4  INC $3E / BNE / INC $3F           ; 码流步进（失败分支亦步进）
87CA  JMP 86D0             ; 回项环
```

- set10 是**项环成员**（非终止单元）：一条记录可含多个 set10 + pair + ctrl 混排。
- **码流耦合**：每 set10 消费 `($3E),0` 一字节——关4 set10×32 ⇒ 码流 32B 消费面
  （码流 = sub_8619 输出执行器族的输入，B1 §1.5；语义未名 S4b-6 同族）。

## 4. 组员滴灌 vs 批量原子（移植关键，A 级）

| 投放通道 | 时序 | 机制 |

## 6. 【2026-10-15 补注】S4b-6/7 小闭合：$EEE5 效果面 + $4B 计数链 + 双分配器差异

> 指派：lead 小闭合轮（S4b-6/7，纯静态）；本节收口 §5 前三行挂账（章节序号 2026-10-15 补注时重排）。

### 6.1 S4b-6a $EEE5(A=8) 效果面（A 级，bank15:EEE5-EF1E）

`JSR $EEE5` **非任意效果调用，是 $48/$49 16 位累加器的加权进位派发**：

```
EEE5  CLC / ADC $48 / STA $48      ; $48 += A（pair 项恒 A=8）
EEEA  BCC ret                       ; 无进位即返回
EEEE  INC $49 / BNE EEF5 / DEC $49 / RTS   ; 高字节++（饱和不回 0）
EEF5  EOR $49 / AND #$F0 / BEQ ret  ; 高半字节变化门
EEFD  LDA $49 / LSR×4 / TAY / LDA $EF49,Y → $04   ; $49>>4 查派发表
EF09  LDA $4A / LSR×4 → $05
EF11  LDY $4C / LDA $180 / CMP $EF81,Y / max→AND #$E …  ; 关号参与钳制
```

- 派发表 `$EF49` 首 16B = `00 00 00 00 01 00 01 00 00 01 01 01 02 01 02 02`（值域 0..2）；
  `$EF81,Y` 钳制表 + 关号 `$180` 参与 ⇒ **累加器派发与关卡联动**（深层语义 S4b-6c 留白）。
- **pair 项权重=8**（86EE `LDA #8`）；三组长/set10 不调 $EEE5。

### 6.2 S4b-6b $4B 消费点（A 级；zp 精确匹配 9 点，$4B41 等绝对址点=噪声不计）

| 点 | 动作 | 语义 |
|---|---|---|
| bank00:86F3-86F7 | INC/DEC 饱和（pair 项每项 +1） | **pair 项连发计数器** |
| bank02:8663-8675 | `LDY $4B / CPY #$12 / < $12 ⇒ LDA $A325,Y / else LDA #1 / JSR $EEE5 / $4B:=0` | **清算点**：计数查权重表 $A325（越界取 1）→ 灌入 $EEE5 累加器 → 清零 |
| bank15:E117 | 初始化块 `$4B:=0` | 关首清零（与 $44-$4B 同批） |
| bank15:E5AC-E5BB | `DEC $4B / 到 0 ⇒ $4B:=3`；条件支 `$4B:=$0F` | **第二消费族**（状态机侧；与 pair 计数共用 zp——复用语义 S4b-6c） |

`$A325` 表首 18B（bank02，file 0x4325）=`4c 3d e6 00 00 00 80 c0 40 00 00 00 40 c0 80 4c 0c d1`
（含 JMP $E63D/$D10C 指令字节——**表区与代码混排**，权重数值义未证）。
链条定谳（A 级结构）：**pair 项 → $4B 计数 → $A325 权重 → $48/$49 累加器（$EEE5）**。

### 6.3 S4b-7 双分配器差异（A 级，bank14:$/C2C6-$/C310 原字节对齐重导）

| 面 | `$C304`（pair 项用） | `$C2C6`（ctrl1/2/11/12/set10 用） |
|---|---|---|
| 扫描 | **单遍顺序** Y=8→$1B | **三级回退** |
| 判据 1 | `$400+槽==0`（空槽）→ CLC/Y=槽 | ①**逆序** Y=$1B→8 同判据空槽 → CLC/Y=槽（零副作用） |
| 判据 2 | — | ②顺序 Y=8→$1B，**type∈[$20,$28) 重指派窗** → 命中走初始化 |
| 判据 3 | — | ③逆序回收候选：`$668+槽 bit7=0 ∧ $41C+槽≠0` → 命中走初始化 |
| 副作用 | 无 | ②/③命中：`JSR $CBAF / JSR $D10C`（槽初始化） |
| 失败 | SEC/Y 未定 | SEC |

- 槽域恒 **8..$1B**（28 槽系统的 8..27 段；0..7=HUD 保留区——N-0120 分区呼应）。
- 判据 ② 的 type 窗 [$20,$28) 与全部观测型值（$2A/$2B/$2E/$2F/$38…）**不相交**——
  窗内型值族未观测（S4b-7b 残余）；判据 ③ 的 `$41C+槽≠0`（行为指针在场）为回收标记候选（B 级注）。
- 移植要点：pair 项=first-fit 零副作用；ctrl/set10=三级回退（空槽→重指派→回收）+初始化副作用——
  **两路径槽序不同（顺序 vs 逆序首级）**，同负载下槽分配轨迹可分歧，属保真面（D4）。
