## 2. 波次链/记录格式（已证实 B 级 + 结构实录）

### 2.1 波次链区（bank8 $AD00-$ADD0，file 0x10D10-0x10DE0）

**分段事件记录流**，段间 `00 FE` 分隔，段内含自引指针 + 行为脚本指针 + 参数：

```
… 39 FD 01 00 D6 B2 | 00 FE | 46 AD 03 00 E6 B2 10 FD 08 00 61 B6 | 00 FE |
   54 AD 05 00 C1 B5 05 00 96 B3 10 FD 08 00 61 B6 | 00 FE |
   66 AD 06 00 01 B5 05 00 11 B6 08 FD 08 00 61 B6 | 00 FE | 78 AD …
```

- 自引指针 `$AD46/$AD54/$AD66/$AD78`（+8/+0x12 递增）→ 段内偏移/子记录；
- 行为脚本指针 `$B2E6/$B5C1/$B501/$B396/$B611/$B661`（bank8 窗内，与 t32 §1.1 同族）；
- 参数对 `03 00/05 00/06 00`（递增小整数 → 时刻/序号候选）、`10 FD/08 FD/08 00`（掩码/参数候选）。
- **记录语义字段切分未闭环**（时刻 vs 序号 vs 掩码）→ 假设 S1。

### 2.2 生成记录 t_005（t32 实证，本轮复核引用）

5 字节 `{参数×3, 行为脚本指针}`；脚本流（如 $B2B4）含嵌套指针 + FE/FC 终止（t32 §1.1）。

> 【2026-10-15 更正（B1 enemy-timeline）】§1 bank 归属与 §2.3「目录」两处收口：
> ① 关卡目录实为 **bank8:$A000 8B/条**（bank00:8000 装载器，Y=$180*8）——bank8=STG-01+**STG-02**、
> bank9=STG-03/04/05、bank10=STG-06/07/08（原文「bank9=STG-02 候选」作废）；
> ② $ACEF 区 `44 AD D0 AD` = STG-02 脚本流 $ACEA 的 cmd1 记录操作数（evt=$AD44/spawner=$ADD0），
> 非独立目录。八关脚本流/敌波调度流/生成器流指针表见 docs/findings/enemy-timeline.md §4.1。

### 2.3 目录（bank8 $ACEF 区）

`44 AD D0 AD` 字样 = 范围对（$AD44-$ADD0 = 波次链块边界）——块范围目录（B 级；
消费方式未定 → 假设 S2）。

## 3. 关卡数据页目录候选（bank2 $8100-$8220）

- 字节值域 **$A0-$BF**（bank8/9/10 窗页号）连续/递增排布；按 LE 字解析 76/144 落 $A000-$BFFF 窗内。
- seed 线性扫描曾误判为代码（`A0 AD` 伪装 `LDY #$AD`，同 t35/t42 教训）——**实为数据表**。
- 消费者未定位（间接寻址）→ 假设 S3（页目录/块索引候选，M3 关卡装载入口线索）。

## 4. 滚动/地形数据定位（已证实 B 级）

- **滚动寄存器变量 = `$1C/$1D`**（S0：NMI `bank15:$EFC8/$EFCD` `STA $2005` 消费）；
  写点：**bank8:$AE87（关卡数据流内！）**、bank9:$824B/$8BF3/$8BF8、bank15:$E815/$E819（固定 bank 更新例程）。
- 结论（B 级）：**滚动指令嵌于关卡数据流**（bank8/9 数据流含 `85 1C` 字节序列）——
  数据流即脚本（生成+滚动混合指令流）；与 §2 分段记录的参数对（`10 FD/08 FD` 型）相容。
- bank1:$AB3B-$AB4C 直写 $2005 = UI 面板滚动（商店卷轴），与关卡滚动无关（区分注记）。
- **地形碰撞数据**：候选 = bank8 $AC80 tile 索引流（t32 §3 观察 `6A 6B 6C 6D 36 37…`）+ bank8/9 头区
  `09 20 28` 公共段（格式未知）→ 假设 S4（未闭环）。

## 5. 关卡长度/切换条件（B-STG-xx-TL 子格证据）— 部分定位

- 波次链**分段结构**（§2.1）= 时间线骨架候选：段序列即关卡推进序；段参数对（`03 00/05 00/06 00` 递增）
  疑为段序/时刻 → 假设 S1 关联。
- 切换条件/关卡长度**未闭环**（终止符/计数未定位）→ 假设 S5；B-STG-xx-TL 子格登记素材 = 本文件
  §1 bank 图 + §2 链结构（t1 matrix §2.3 子格规则由 spec-writer/captain 登记）。
- **STG-01 交叉验证（④）**：gameplay-stage1 trace（iram 对象churn 1090/1090 帧活跃）证实 STG-01 敌出现
  全程连续；与 §2 波次链段序列的**逐时刻对齐**待段参数语义（S1）定谳后可做——现登记为：
  波次时刻表 = bank8 $AD00 区（定位✓）、帧级对齐 = 待 S1（负结果/未闭环如实登记）。

## 6. 复现命令

```bash
# 波次链/目录/生成记录（bank8）
xxd -s 0x10CE0 -l 176 rom/gunnac_cn.nes     # $ACEF 目录 + $AD00 链头
xxd -s 0x10D50 -l 96 rom/gunnac_cn.nes      # 分段事件记录（00 FE 分隔段）
xxd -s 0x10DE0 -l 64 rom/gunnac_cn.nes      # t_005 生成记录（5 字节组）
# bank9/10 头对照（其余关定位）
xxd -s 0x12010 -l 64 rom/gunnac_cn.nes; xxd -s 0x14010 -l 64 rom/gunnac_cn.nes
# 关卡数据页目录（bank2 数据表；注意 seed 误判为代码）
xxd -s 0x4110 -l 288 rom/gunnac_cn.nes
# 滚动写点
grep -n "STA     \$1C\b\|STA     \$1D\b\|STA     \$2005" reference/seed/gunnac.asm | head
```
