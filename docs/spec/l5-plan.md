## 3. DSL 扩展需求清单（现 DSL 表达不了的部分）

现 DSL（`oracle/scenarios/README.md`）：`name/frames/press_len/press/hold/capture/capture_every/
watch/watch_range/ramframe`——**开环输入轨道**，无条件分支/无快照/无种子控制。

| # | 扩展 | 需求描述 | 服务于 | 优先级 |
|---|---|---|---|---|
| C1 | **随机种子控制** | 注入/冻结 RNG（或显式记录并回放 RNG 流）：`bomb_type_index` 初始化（bank15:E138 RNG）、拾取/敌人生成涉随机；确定性长跑必备 | S5-ALL-CLEAR | 高 |
| C2 | **存档/续关支持** | 模拟器 save-state 快照/载入指令（`snapshot <tag>` / `restore <tag>`）；若本作有电池存档机制则另需存档文件断言（机制未证） | 分段接力、GAME OVER 路径 | 高 |
| C3 | **长场景分段 checkpoint** | 场景分段定义（`segment <名> <起>-<止>`）+ 段间状态断言文件 + 段结果汇总为一个 L5 裁定（单跑 3-5 万帧不现实，需快照续跑） | S5-ALL-CLEAR | 高 |
| C4 | **条件输入（分支轨道）** | `when <watch条件> then press/hold`（对游戏状态反应：躲避/瞄准）；或离线生成"工具辅助输入轨"后回放开环播放 | 通关可行性（不开环无法稳定通关弹幕） | 中 |
| C5 | **视觉断言点** | `assert_screen <帧> <预期图>` + 白名单引用（对接 L4 diff_visual） | A4 | 中 |
| C6 | **输入纯净断言（内建）** | `expect_held` 排程表 → 自动断言 0 计划外按键位（t28 复核脚本的 DSL 化） | A5（防幻影输入回归） | 中 |
| C7 | **事件窗遮蔽声明** | `mask <起>-<止> <理由>`：L3/L5 差分显式遮蔽事件窗口（现为驱动层隐式行为，声明化可审计） | R-respawn 窗口、H-16 | 低 |
| C8 | **长跑资源治理** | 帧数上限/超时分级、trace 体积采样（长跑全帧 RAM 不可行）+ `.scenario.lock` 语义延伸 | S5-ALL-CLEAR | 低 |
